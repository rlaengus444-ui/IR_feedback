# IR 피드백 외부 모듈 · CSV

버전: `2026.10.30-csv-wait.2` 검증 후보. [CSV 갱신 시 연결 유지](../docs/CSV_OBSERVATION_WAIT.ko.md)를 추가합니다. [첫 탭 경로 자동 불러오기](../docs/AUTO_SLICE.ko.md)를 추가합니다. 기존 수동 이미지 입력, 설정 변경 시 연결 유지와 CSV·온도·IR PNG 자동 저장은 유지합니다. 원본 BinderJet 소스·실행 파일·설정을 추가로 바꾸지 않고, 기존 Monitoring CSV에 새 완료 행이 저장되면 `TemperaturePostRecoating`을 읽어 IR 설정을 계산합니다. Process 표 조회·접근성 객체·스크롤·Process 탭 전환은 사용하지 않습니다.

**온도 신뢰성:** 온도계 비활성 상태를 나타내는 -1 값은 제어 입력으로 사용하지 않습니다. 정상 범위의 오래된 센서값은 CSV만으로 감지할 수 없습니다. 실제 S3 센서·PLC·램프 출력은 미검증이며 제어 알고리즘 최종 승인과 장비 적용은 보류 상태입니다.

이전 `2026.10.27-background.1`은 사용 보류 버전입니다. 이번 CSV 버전은 데이터 수신 경로를 교체한 것이며, 원본 프로그램 자체의 Process 화면 정지 원인을 해결했다고 의미하지 않습니다.

## 실행

1. 이전 외부 모듈을 완전히 닫습니다. 새 ZIP을 **새 폴더에 전체 압축 해제**합니다.
2. `IRFeedback.exe`를 실행합니다. Python 설치·환경변수·PID 입력은 필요 없습니다.
3. M1/S3와 자동 검색된 원본 창을 선택하고 **연결**합니다. 화면에는 **UI 자동 적용**만 표시합니다. 실행·검색만으로 연결하거나 IR을 저장하지 않습니다.
4. 목표 온도 기본값은 65°C입니다. 연결 전 값을 입력하거나, 연결 중 값을 바꾼 뒤 **목표 적용**을 누르면 다음 새 층부터 사용합니다. 버튼을 누른 즉시 IR을 저장하지 않습니다.
5. 알고리즘·계산시트·셀 주소는 연결 전에 지정합니다. 제공 계산시트 두 종류의 이미지 시작셀 기본값은 **BL13**입니다. 다른 양식은 주소를 바꾸거나 비울 수 있습니다.
6. 자동 적용 준비에서 기존 Sequences 설정을 한 번 확인합니다. Process 화면으로 이동하지 않습니다. 준비 후 다른 탭을 보거나 최소화할 수 있습니다.
7. **연결 해제**는 외부 작업만 종료합니다. 원본 종료·히터 ON/OFF·이전 IR 복원은 실행하지 않습니다.

## Excel 알고리즘 선택

기본 알고리즘 또는 **Excel 수식 파일**을 선택할 수 있습니다. Excel을 선택하면 `.xlsx` 파일, T_recoating 입력 시작셀, 계산된 다음 IR 출력의 수식 시작셀을 지정합니다. 현재 IR을 입력할 셀, 목표 온도 셀, 선택적인 층 번호 입력셀도 지정합니다. 시트 이름을 비우면 첫 번째 시트를 사용합니다. 기존 80층 파일의 예시는 각각 `B13`, `D13`, `C13`, `B5`, `A13`입니다.

층별 시작셀은 같은 행이어야 하며 연결 후 받은 첫 새 층을 시작 행에 넣고 이후 층은 다음 행에 기록해 계산합니다. 이전 테스트 값이 섞이지 않도록 입력 열은 초기화하며, 수식 범위가 끝나거나 지원하지 않는 파일·수식이면 중단합니다. 파일과 셀 설정은 연결 해제 후 변경합니다.

Excel 옵션은 이 PC에 설치된 **Microsoft Excel 데스크톱**의 계산 엔진이 필요합니다. 선택한 원본 파일은 저장하지 않고 격리 복사본을 읽기 전용으로 열며, 매크로와 외부 연결은 허용하지 않습니다. 계산 결과는 0~100% 범위와 1회 최대 5%p 증감 보호를 적용합니다. 임의 Excel의 모든 기능이 지원되는 것은 아닙니다. Python 설치는 필요 없습니다.

## 슬라이싱 이미지와 수동 계산시트

ZIP 또는 이미지 다중 선택으로 중앙 반경 mm의 데이터를 분석합니다. 기본 흰색 분사, DPI 400×400을 변경할 수 있으며, 현재·이전 층 데이터를 별도로 Excel에 전달합니다. 내장 기본 알고리즘과 시트 저장 버튼의 기본 템플릿은 기존과 같습니다. 별도로 전달한 이미지 회복제어 / 파우더층 제어·분사층 출력 고정 시트는 `Excel 수식 파일 → 찾아보기`로 직접 선택하며 이미지 시작셀은 `BL13`입니다. [입력 방법과 셀 대응표](../docs/SLICE_INPUT.ko.md)를 확인하세요. 기존 csv.6 EXE에는 이 기능이 없으며, 제어 알고리즘의 최종 승인과 실제 장비 적용은 보류 중입니다.

## 층별 그래프

**층별 그래프**에서 연결 후 수신한 층의 T_recoating과 IR 설정을 확인합니다. IR 선은 CSV 수신 시 읽힌 설정, 점은 해당 수신 후 Save가 성공한 값입니다. 실제 램프 출력의 측정값은 아닙니다. 기본 그래프는 최근 100개 층만 표시하고, 전체보기 버튼을 누르면 연결 후 수신한 전체 층을 별도 창에서 볼 수 있습니다. 새 층이 들어오면 두 창이 갱신됩니다. 기록은 현재 연결 및 작업 범위에서 유지하며, 재연결하거나 다른 작업이 시작되면 초기화됩니다. 연결 전 이력은 자동으로 채우지 않습니다.

**CSV 저장**을 누르면 최근 100층이 아닌 현재 연결에서 수신한 전체 층의 온도, IR 설정과 Save 성공값을 CSV로 저장합니다. 공통 IR은 IR 1 또는 공통 열에 기록하고, 측정되지 않은 값은 빈칸으로 둡니다. IR 설정은 램프 실측 출력이 아닙니다. Excel에서 한글을 읽을 수 있도록 UTF-8 BOM으로 저장됩니다.

**연결 해제 시 CSV 자동 저장**: 해제 버튼과 오류로 연결이 종료된 경우 모두 누적 그래프의 전체 기록을 저장합니다. 실행 파일 옆 **records** 폴더를 사용하며 쓰기 권한이 없으면 **%LOCALAPPDATA%/IRFeedback/records**에 저장합니다. 파일 위치와 행 수는 상태 기록에 남깁니다. 작업 전환으로 그래프가 초기화되는 경우에도 이전 기록을 보관해 작업별 파일로 저장하며 기존 파일은 덮어쓰지 않습니다.

파일 쓰기는 별도 작업에서 진행하므로 재연결을 기다리게 하지 않습니다. 프로그램을 닫을 때는 종료 시점의 남은 그래프 관찰을 정리하고 CSV 쓰기가 끝난 뒤 창을 닫습니다. 저장 실패 기록은 재연결 후에도 메모리에 유지하며, 프로그램 종료 시에도 실패하면 다른 폴더를 선택할 수 있게 합니다. 폴더 선택을 취소하면 기록과 창을 유지합니다. 모듈이 수신하지 않은 과거 데이터나 아직 성공이 확인되지 않은 Save 값은 생성하지 않습니다.

그래프의 지점에 마우스를 올리면 해당 층과 온도 또는 IR 설정값이 표시됩니다. 온도 그래프의 점선은 현재 목표 온도입니다. 목표 변경을 예약하면 새 층에 적용될 때 기준선이 바뀝니다. 기준선은 현재 목표를 나타내며 과거 모든 층에서 같은 목표가 사용되었다는 의미는 아닙니다.

Windows 64비트, 원본과 같은 사용자·권한 수준이 필요합니다. 원본이 관리자 권한이면 외부 모듈도 같은 권한으로 실행합니다.

## 데이터와 제어 시점

원본은 T_recoating을 측정 후 메모리에 기록하고, 해당 층의 인쇄가 끝난 뒤 Monitoring CSV에 저장합니다. 따라서 이 버전은 **측정 즉시 제어가 아닌, CSV 저장 직후 제어**입니다. 사이클이 약 60초여도 측정과 파일 저장 사이의 지연은 남습니다. UI에는 현재 운전 층 대신 **최근 완료 층**을 표시합니다.

외부 모듈은 약 0.25초 간격으로 새 데이터를 확인합니다. 새 CSV 행의 파싱이 끝나면 계산하고, 변경이 필요할 때만 기존 Sequences의 IR 입력과 Save를 사용합니다. 실제 히터의 출력 반영 시점은 원본의 공정·설정 갱신 동작에 따릅니다.

기존 원본 로그의 장비별 작업 시작·첫 층 시각과 일치하는 CSV를 Desktop/Monitoring 또는 기존 `BINDERJET_UNIFIED_MONITORING_ROOT`에서 자동으로 찾습니다. 다른 작업의 최신 파일을 추측해서 선택하지 않습니다. 후보가 여러 개거나 작업 로그를 확인할 수 없으면 기다리거나 명확한 오류로 중단합니다. 첫 CSV는 첫 층 인쇄 완료 전까지 없을 수 있습니다.

중간 층부터 작업을 재개해 CSV 앞부분에 이전 실행 기록이 남아 있으면, 시작 층보다 앞서고 시작 시각보다 충분히 오래된 완료 행만 제외합니다. 이 경우 로그와 정확히 대응하는 재시작 첫 행을 확인해야 합니다. 온도 0이나 미완료 행은 작업 확인에만 쓰며 온도로 사용하지 않습니다. 그 뒤 첫 유효 완료 온도도 기준값으로만 사용하고 다음 새 층부터 계산합니다. 부분 행·분할 읽기에도 이 조건을 유지합니다. 기존 행에서 계산·Save를 재실행하지 않습니다. 층과 시각이 충돌하는 행, 현재 구간 뒤에 섞인 과거 행과 비활성 온도 -1은 계속 오류로 중단합니다.

슬라이싱의 **첫 파일 대응 층**은 선택한 첫 이미지의 실제 층 번호입니다. 1층부터 전체 이미지를 선택했다면 프린팅 재개 층과 관계없이 1을 유지합니다. CSV의 작업 식별과는 독립입니다. 오류가 발생하면 `app/IR-module-error.log`에 문구가 기록되며, 작업 일치 오류에는 CSV Id·행 시각·로그 기준 층과 시각을 함께 남깁니다.

연결 전에 있던 행은 표시만 합니다. 연결 후 새 행마다 한 번 계산하며, 기본 알고리즘은 첫 두 새 관찰에서 기존 설정을 유지합니다. Excel 알고리즘은 파일의 수식에 따라 첫 새 관찰부터 변경을 권할 수 있습니다. 같은 행·같은 권장값을 반복 저장하지 않습니다. 한 번의 증감은 최대 5%p, 출력 범위는 0~100%이고 소수 설정을 보존합니다. 원본의 공통 IR 설정은 두 독립 채널로 제어하지 않습니다.

## 설정 변경과 플롯 자동 저장

[동작 및 저장 위치](../docs/LIVE_SETTINGS.ko.md)를 확인하세요. 설정을 편집하는 동안 연결과 CSV 조회·그래프는 유지하고 IR 적용만 대기합니다. 저장값과 화면 값을 두 번 확인한 뒤 첫 유효 관찰을 기준으로 읽고 다음 새 층부터 계산합니다. 자동으로 편집값을 저장하거나 탭을 열지 않습니다. CSV·온도 PNG·IR PNG의 전체 파일 경로는 상태 기록에 남습니다. 일부 저장 실패 시 완료된 파일은 보존하고 실패 항목만 재시도합니다.

## 오류와 보호 동작

- 완성된 CSV 레코드만 사용합니다. 따옴표·쉼표·줄바꿈과 기록 중인 부분 행을 구분합니다.
- 정확한 `TemperaturePostRecoating` 열만 사용합니다. 다른 온도 열을 대신 쓰지 않습니다.
- 과거·중복·오래된 행, 기본값 0/미측정 행, 작업 변경·층 역행, 비정상 수치와 불완전한 입력은 저장하지 않습니다.
- IR 입력 전과 Save 전에 CSV 크기·수정 시각·SHA-256 내용 해시, AUTO/RUNNING, 현재 운전 층, 원본 설정과 다른 모든 Sequence 입력을 대조합니다. 같은 길이로 덮어쓰고 수정 시각을 유지한 변경도 확인하며, 이미 읽은 CSV 내용이 바뀌면 새 제어 입력으로 재사용하지 않습니다.
- 원본 UI의 읽기 응답만 실패하면 CSV 조회는 계속하고 IR 적용·학습은 정지합니다. UI가 회복되어도 기존 행을 재저장하지 않습니다.
- 입력이나 Save가 실행됐을 수 있는 오류는 결과 불명확으로 중단합니다. 재저장·원복·히터 정지를 자동 실행하지 않습니다.
- 원본에 미저장 편집값이 있으면 IR 적용을 대기합니다. 기존 Save는 여러 설정을 함께 저장할 수 있으므로 저장값과 화면의 전체 값을 다시 확인한 뒤 새 층부터 재개합니다.

CSV는 공유 읽기 모드로 짧게 열며, 원본의 추가 쓰기와 파일 교체를 막지 않습니다. 파일 32 MiB·행 64 KiB·작업 폴더 후보 4,096개와 읽기 크기 상한을 둡니다. UI 도우미가 멈추면 외부 모듈이 생성한 도우미만 종료합니다. 원본 프로세스를 종료하거나 잠시 멈추거나 코드를 주입하지 않습니다.

## 알고리즘과 검증 범위
