# IR 피드백 외부 모듈 · CSV

버전: `2026.10.27-csv.3`. 원본 BinderJet 소스·실행 파일·설정을 추가로 바꾸지 않고, 기존 Monitoring CSV에 새 완료 행이 저장되면 `TemperaturePostRecoating`을 읽어 IR 설정을 계산합니다. Process 표 조회·접근성 객체·스크롤·Process 탭 전환은 사용하지 않습니다.

이전 `2026.10.27-background.1`은 사용 보류 버전입니다. 이번 CSV 버전은 데이터 수신 경로를 교체한 것이며, 원본 프로그램 자체의 Process 화면 정지 원인을 해결했다고 의미하지 않습니다.

## 실행

1. 이전 외부 모듈을 완전히 닫습니다. 새 ZIP을 **새 폴더에 전체 압축 해제**합니다.
2. `IRFeedback.exe`를 실행합니다. Python 설치·환경변수·PID 입력은 필요 없습니다.
3. M1/S3와 자동 검색된 원본 창을 선택하고 **연결**합니다. 기본은 조회입니다.
4. 목표 온도 기본값은 65°C입니다. 연결 전 값을 입력하거나, 연결 중 값을 바꾼 뒤 **목표 적용**을 누르면 다음 새 층부터 사용합니다. 버튼을 누른 즉시 IR을 저장하지 않습니다.
5. 실제 적용은 연결 해제 후 **UI 자동 적용**을 선택하고 다시 연결합니다.
6. 자동 적용 준비에서 기존 Sequences 설정을 한 번 확인합니다. Process 화면으로 이동하지 않습니다. 준비 후 다른 탭을 보거나 최소화할 수 있습니다.
7. **연결 해제**는 외부 작업만 종료합니다. 원본 종료·히터 ON/OFF·이전 IR 복원은 실행하지 않습니다.

## Excel 알고리즘 선택

기본 알고리즘 또는 **Excel 수식 파일**을 선택할 수 있습니다. Excel을 선택하면 `.xlsx` 파일, T_recoating 입력 시작셀, 계산된 다음 IR 출력의 수식 시작셀을 지정합니다. 현재 IR을 입력할 셀, 목표 온도 셀, 선택적인 층 번호 입력셀도 지정합니다. 시트 이름을 비우면 첫 번째 시트를 사용합니다. 기존 80층 파일의 예시는 각각 `B13`, `D13`, `C13`, `B5`, `A13`입니다.

층별 시작셀은 같은 행이어야 하며 연결 후 받은 첫 새 층을 시작 행에 넣고 이후 층은 다음 행에 기록해 계산합니다. 이전 테스트 값이 섞이지 않도록 입력 열은 초기화하며, 수식 범위가 끝나거나 지원하지 않는 파일·수식이면 중단합니다. 파일과 셀 설정은 연결 해제 후 변경합니다.

Excel 옵션은 이 PC에 설치된 **Microsoft Excel 데스크톱**의 계산 엔진이 필요합니다. 선택한 원본 파일은 저장하지 않고 격리 복사본을 읽기 전용으로 열며, 매크로와 외부 연결은 허용하지 않습니다. 계산 결과는 0~100% 범위와 1회 최대 5%p 증감 보호를 적용합니다. 임의 Excel의 모든 기능이 지원되는 것은 아닙니다. Python 설치는 필요 없습니다.

## 층별 그래프

**층별 그래프**에서 연결 후 수신한 층의 T_recoating과 IR 설정을 확인합니다. IR 선은 CSV 수신 시 읽힌 설정, 점은 해당 수신 후 Save가 성공한 값입니다. 실제 램프 출력의 측정값은 아닙니다. 그래프는 최근 2,000층까지 유지하며 연결 전 이력을 자동으로 채우지는 않습니다.

그래프의 지점에 마우스를 올리면 해당 층과 온도 또는 IR 설정값이 표시됩니다. 온도 그래프의 점선은 현재 목표 온도입니다. 미리보기·자동 적용에서 목표 변경을 예약한 경우 새 층에 적용될 때 기준선이 바뀝니다. 조회 모드에서는 설정한 조회 기준을 표시합니다. 기준선은 현재 목표를 나타내며 과거 모든 층에서 같은 목표가 사용되었다는 의미는 아닙니다.

Windows 64비트, 원본과 같은 사용자·권한 수준이 필요합니다. 원본이 관리자 권한이면 외부 모듈도 같은 권한으로 실행합니다.

## 데이터와 제어 시점

원본은 T_recoating을 측정 후 메모리에 기록하고, 해당 층의 인쇄가 끝난 뒤 Monitoring CSV에 저장합니다. 따라서 이 버전은 **측정 즉시 제어가 아닌, CSV 저장 직후 제어**입니다. 사이클이 약 60초여도 측정과 파일 저장 사이의 지연은 남습니다. UI에는 현재 운전 층 대신 **최근 완료 층**을 표시합니다.

외부 모듈은 약 0.25초 간격으로 새 데이터를 확인합니다. 새 CSV 행의 파싱이 끝나면 계산하고, 변경이 필요할 때만 기존 Sequences의 IR 입력과 Save를 사용합니다. 실제 히터의 출력 반영 시점은 원본의 공정·설정 갱신 동작에 따릅니다.

기존 원본 로그의 장비별 작업 시작·첫 층 시각과 일치하는 CSV를 Desktop/Monitoring 또는 기존 `BINDERJET_UNIFIED_MONITORING_ROOT`에서 자동으로 찾습니다. 다른 작업의 최신 파일을 추측해서 선택하지 않습니다. 후보가 여러 개거나 작업 로그를 확인할 수 없으면 기다리거나 명확한 오류로 중단합니다. 첫 CSV는 첫 층 인쇄 완료 전까지 없을 수 있습니다.

연결 전에 있던 행은 표시만 합니다. 연결 후 새 행마다 한 번 계산하며, 기본 알고리즘은 첫 두 새 관찰에서 기존 설정을 유지합니다. Excel 알고리즘은 파일의 수식에 따라 첫 새 관찰부터 변경을 권할 수 있습니다. 같은 행·같은 권장값을 반복 저장하지 않습니다. 한 번의 증감은 최대 5%p, 출력 범위는 0~100%이고 소수 설정을 보존합니다. 원본의 공통 IR 설정은 두 독립 채널로 제어하지 않습니다.

## 오류와 보호 동작

- 완성된 CSV 레코드만 사용합니다. 따옴표·쉼표·줄바꿈과 기록 중인 부분 행을 구분합니다.
- 정확한 `TemperaturePostRecoating` 열만 사용합니다. 다른 온도 열을 대신 쓰지 않습니다.
- 과거·중복·오래된 행, 기본값 0/미측정 행, 작업 변경·층 역행, 비정상 수치와 불완전한 입력은 저장하지 않습니다.
- IR 입력 전과 Save 전에 CSV 크기·수정 시각, AUTO/RUNNING, 현재 운전 층, 원본 설정과 다른 모든 Sequence 입력을 대조합니다.
- 원본 UI의 읽기 응답만 실패하면 CSV 조회는 계속하고 IR 적용·학습은 정지합니다. UI가 회복되어도 기존 행을 재저장하지 않습니다.
- 입력이나 Save가 실행됐을 수 있는 오류는 결과 불명확으로 중단합니다. 재저장·원복·히터 정지를 자동 실행하지 않습니다.
- 원본 설정을 동시에 수동 편집하지 마세요. 기존 Save는 여러 owner 설정을 저장하므로 원본의 다른 설정 화면에도 미저장 편집값이 없어야 합니다.

CSV는 공유 읽기 모드로 짧게 열며, 원본의 추가 쓰기와 파일 교체를 막지 않습니다. 파일 32 MiB·행 64 KiB·작업 폴더 후보 4,096개와 읽기 크기 상한을 둡니다. UI 도우미가 멈추면 외부 모듈이 생성한 도우미만 종료합니다. 원본 프로세스를 종료하거나 잠시 멈추거나 코드를 주입하지 않습니다.

## 알고리즘과 검증 범위

알고리즘은 [Notion IR 출력 제어 자료](https://app.notion.com/p/3f105e94a225801c9cd6c70784c2d9ec)의 `IR_출력제어_수동테스트_랜덤패턴_80층.xlsx` 수식입니다. 원본 SHA-256은 `2dbdff1057ab0a2f0bbe539b77ffb71782f10daf61f8d111236d6f5585e16a94`입니다. 랜덤 80층과 입력 예시 67행, 총 8,085개 수치 비교를 제공합니다.

S3 선택과 매핑은 포함하지만 기존 S3 설정에 필요한 항목이 누락돼 있으면 자동 적용을 거부합니다. 누락 설정을 임의 생성하지 않습니다. CSV 기록 자체가 물리 센서 읽기의 성공이나 실제 램프 출력을 독립적으로 증명하지는 않습니다.

실제 장비의 IR 출력을 변경하는 시험과 장시간 열 제어 안정성은 검증하지 않았습니다. 새 버전의 시험 결과와 한계는 `VALIDATION.ko.md`를 확인하세요. 이전 버전에서 원본 UI 정지가 보고됐으므로 모의 검증 통과를 실장비 안전 보장으로 해석하지 않습니다.
