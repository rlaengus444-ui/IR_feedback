# 계산 결과의 작업·층 유효성

`2026.11.12-layer-validity.1`은 같은 작업의 최신 완료 층 계산을 시간이 지났다는 이유로 폐기하지 않습니다. CSV·계산 결과의 3초/5초 유효 시간과 IR 입력 전 2초 여유 조건을 제거했습니다. Excel STEP 계산의 8초/45초 상한도 제거했습니다. 60초 같은 대체 만료 시간은 두지 않습니다.

현재 연결에서 새로 받은 완전한 유효 온도, 현재 작업의 시작 기록, AUTO 상태, 현재 운전 층과 최신 CSV 행의 일치, CSV·작업 로그의 내용 해시를 확인해 저장합니다. 계산 중 CSV 완료 행·작업·현재 층·설정·목표·IR 상한·이미지가 바뀌면 이전 결과를 쓰지 않습니다. 같은 행을 두 번 저장하지 않으며 과거 연결 전 기록은 기준 관찰로만 사용합니다. 온도계 비활성 값 -1과 미래 시각 오류는 계속 차단합니다.

Excel은 현재 관측이 유효하고 프로세스가 살아 있는 동안 계산 완료를 기다립니다. CSV·그래프와 변경 확인은 별도 흐름으로 계속됩니다. 진행 중 계산이 새 관측으로 무효가 되면 해당 전용 작업을 종료하고 종료 확인 후 보존한 동일 계산시트 복사본으로 최신 층 계산을 준비합니다. 이미 무효가 된 계산 뒤에 reset을 무기한 대기시키지 않습니다. 목표나 상한 변경만으로 같은 층을 재계산해 저장하지 않으며 새 층부터 적용합니다.

프로세스 종료·통신 오류·사용자 연결 해제 감지와 초기 준비·reset·UI 읽기 작업의 응답 제한은 유지합니다. IR 상한·층당 최대 5%p 변화·Save 지연 추적·완료 확인 후 자동 재개·프린팅 재시작·PID 자동 연결·이미지 입력·CSV 및 두 PNG 저장 기능을 유지합니다.

실제 BJT·센서·PLC·램프 및 Excel COM 검증과 최종 장비 적용 승인은 별도이며 이 평가판만으로 완료를 뜻하지 않습니다.
