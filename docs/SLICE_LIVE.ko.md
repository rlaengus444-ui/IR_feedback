버전 `2026.10.29-reconnect.3`은 최신 배포 `2026.10.29-reconnect.2`를 기준으로 설정 변경 시 연결 유지와 두 PNG 자동 저장을 추가합니다. [상세 동작](LIVE_SETTINGS.ko.md)을 확인하세요. CSV 재시작 시작 행 확인 수정은 유지합니다. S3 연결 수정·DLL 보호·연결 중 이미지 교체·분석 속도 개선을 유지합니다. 계산시트·알고리즘 종류와 셀 설정은 연결 해제 후 변경합니다. 내장 제어 수식과 기존에 전달한 Excel 두 종류는 변경하지 않습니다.

화면에는 UI 자동 적용만 남기고 사용자가 연결 버튼을 눌러야 기존 제어 준비를 시작합니다. 시작·검색·셀 주소 편집으로 연결하거나 Save를 실행하지 않습니다. 제공 계산시트의 이미지 시작셀 기본값은 BL13이며 다른 양식은 수정하거나 비울 수 있습니다.

## 연결 종료 CSV 자동 저장

정상 해제와 오류 종료에서 연결 종료 이벤트까지 누적된 그래프 기록을 전체 CSV로 저장합니다. 최근 100층 표시와 독립이며 기존 수동 CSV와 같은 7개 열·UTF-8 BOM을 사용합니다. 관찰한 IR 설정과 성공이 확인된 Save 값은 구분합니다. 작업 변경·재연결로 그래프를 초기화하기 전에 이전 구간을 불변 복사본으로 보관하며, 반복된 종료 이벤트는 중복 파일을 만들지 않습니다.

하나의 별도 파일 작업자가 실행 파일 옆 records 폴더에 고유 이름을 예약하고 원자적으로 씁니다. 쓰기 권한 등이 없으면 사용자 LocalAppData의 IRFeedback/records로 시도합니다. 저장 위치·행 수와 실패 여부를 상태 기록에 남깁니다. 실패 복사본은 그래프 초기화·재연결로 지우지 않고 다음 시도까지 유지합니다.

프로그램 종료 중에는 대기 중 그래프 관찰만 배출하며 권장값·연결 상태·제어 허용을 복원하지 않습니다. 기존 종료 제한 시간이 지나면 그 시점까지 관찰한 기록을 보관하고 미확인 Save 성공을 추정하지 않습니다. CSV 쓰기는 UI와 제어를 막지 않습니다. 저장에 실패하면 다른 폴더를 선택할 수 있으며 취소 시 창과 기록을 유지합니다.

확정한 종료 관찰 시점은 저장 실패·취소·재시도 동안 유지합니다. 그 이후 늦게 도착한 이벤트로 그래프나 보존 복사본을 변경하지 않습니다.

2,000행 초과·여러 이벤트 배치·오류 후 종료·빠른 재연결·A→B→A 작업·중복 이벤트·닫기 제한 시간·느린 쓰기·실패 보존과 폴더 재선택을 모의 시험합니다. 이 시험은 실장비 및 Excel COM 검증을 대신하지 않습니다.

## CSV 재연결

제공된 실제 CSV 세 파일(4·478·640행)의 원본을 보존하고 총 1,122행을 기존 배포와 수정 코드에 각각 재생했습니다. 세 번째 파일은 이전 실행의 478행을 그대로 포함하고, Id 479~500은 미시작 기본 행, Id 501은 09:50:38에 시작한 온도 0의 재시작 첫 행입니다. 기존 버전은 이 행의 시작 정보까지 건너뛰어 Id 502의 정상 온도 65.6°C에서 사진과 같은 오류를 냈습니다. 수정 코드는 세 파일 전체 읽기와 세 번째 파일의 단계별 수신을 통과했습니다.

재시작 첫 행의 층·시각 확인과 온도값 사용 조건을 구분합니다. 온도 0 또는 미완료 행을 작업 확인에만 사용하며, Id 502처럼 첫 유효 완료 온도는 기준값으로만 읽고 그다음 새 적격 층부터 계산합니다. 부분 행·분할 읽기에서도 기준값 대기를 유지합니다. 잘못된 시각·중복 시작 행 충돌·온도 -1·확인 뒤에 다시 섞인 과거 완료 행은 거부합니다. 실제 CSV를 재생한 모의 세션에서 과거 행·온도 0 시작 행·첫 유효 기준 행은 계산/Save 0회였고 다음 새 층만 계산 및 모의 Save 1회였습니다. 실제 M1 로그 파일은 제공되지 않아 화면의 시작 층·시각과 CSV 파일명·행을 사용해 문맥과 시계를 재구성했습니다. 실제 장비 Save 및 Excel COM 시험을 뜻하지 않습니다.

중간 층부터 다시 시작한 작업은 CSV에 이전 실행의 완료 행이 남아 있을 수 있습니다. 이전 버전은 앞선 행을 현재 작업과 비교하면서 `CSV 행이 현재 작업의 시작 시점/층과 일치하지 않습니다.` 오류로 중단했습니다. 이 경로를 합성 로그·CSV로 재현했습니다. 실제 사용자 장비에서 처음 연결이 끊긴 원인은 오류 기록이 없어 확정하지 않습니다.

수정판은 CSV 앞부분에서 현재 시작 층보다 작고, 시작·완료 시각이 모두 로그의 작업 시작보다 2초를 초과해 오래된 완료 행만 이전 기록으로 제외합니다. 데이터 형식·온도 범위·비활성 값 -1·시작/완료 시각의 순서는 계속 검증합니다. 이전 기록을 제외한 경우에는 로그의 정확한 시작 층과 ±2초 이내의 시작 시각을 가진 기준 행을 확인해야 합니다. 그 확인은 기준 설정이며 제어를 재실행하지 않습니다. 이후 새로 수신한 적격한 층만 계산 대상이 됩니다.

층은 과거인데 시각은 현재인 행, 현재 층인데 시각은 과거인 행, 현재 구간 뒤에 나타나는 과거 행은 오류입니다. 작업 변경·파일 교체·축소·내용 재작성 시에는 구간 확인 상태를 초기화하고 새 기준을 세웁니다. 기존 CSV 선택·해시·신선도·층별 Save 보호와 결과가 불명확한 Save의 재시도 금지는 유지합니다.

슬라이싱의 첫 파일 대응 층은 이미지와 실제 층을 연결하는 설정입니다. 전체 이미지를 1층부터 선택했다면 재연결 시에도 1이 맞습니다. CSV 연결 오류를 해결하기 위해 이 값을 현재 프린팅 층으로 바꾸지 않습니다.

모의 재연결에서 과거 행과 기준 행의 계산·저장이 0회인지, 이후 새 적격 행만 한 번 계산하는지 확인합니다. Windows 패키지 시험과 독립 검토 결과는 해당 후보의 별도 검증 증거로 보존하며, 실제 Excel COM·장비 시험은 미실행입니다. 최종 제어 승인과 장비 적용은 계속 보류합니다.

## 이미지 교체

새 파일을 분석하는 동안 기존의 완료된 데이터가 계속 사용됩니다. 분석 취소·실패·오래된 분석 결과로 활성 데이터를 덮어쓰지 않습니다. 최신 분석이 완전히 끝났을 때 세션에 교체를 예약하며, 실제 반영은 작업자 스레드가 수행합니다. 재연결 전 시작한 오래된 분석이 다른 연결에 자동 반영되지 않도록 구분합니다.

이미지를 입력하는 Excel은 전용 임시 시트를 원본 복사본에서 다시 열어 제어 이력을 초기화합니다. 현재 관찰을 기준으로 삼고 다른 새 층의 측정부터 계산합니다. 원본 파일을 수정하거나 계산 완료 행의 이미지 값만 바꾸지 않습니다. 초기화 실패 시 혼합된 이력으로 계산하지 않습니다. 그래프·CSV의 실제 측정·저장 이력은 유지합니다.

교체 요청 전에 이미 허용된 저장은 기존 데이터로 완료·검증할 수 있습니다. 다음 히터를 포함한 이후 구버전 권장값은 새로 적용하지 않습니다. 조회와 미리보기는 장비 설정을 저장하지 않습니다. 이미지로 제어하지 않는 내장 기본 알고리즘과 이미지 입력 없는 Excel의 이력은 그대로 유지합니다.

## 속도 개선

같은 분석 안에서 이미지 전체 바이트의 SHA-256이 같으면 성공한 수치 결과를 재사용합니다. 저장하는 항목은 최대 256개 수치 묶음이며 디코딩된 이미지 여러 장을 보관하지 않습니다. ZIP 파일은 매번 끝까지 읽어 CRC와 크기 오류를 검사합니다. 층별 기록·층 번호·연속 무분사 수와 전체 데이터 지문은 유지합니다.

투명도·팔레트·반전·픽셀 중심 원형 영역과 통계 수식은 유지합니다. 투명도가 없는 8비트 회색조 이미지는 같은 픽셀의 불필요한 복사를 생략합니다. 추가 라이브러리나 병렬 디코딩은 사용하지 않습니다.

Linux의 4,096×4,096 모의 ZIP에서 반복 96층(서로 다른 바이트 3개) 중앙값은 약 7.10→0.18초, 팔레트 24층(4개)은 2.01→0.37초였습니다. 서로 다른 48층의 같은 시점 교차 실행은 3.31→3.01초였고, 별도 실행 최고 메모리는 약 49→33 MiB였습니다. 파일 내용·용량·PC에 따라 효과가 다르며, 이 값은 실제 사용자 ZIP이나 Windows 장비의 측정값이 아닙니다.

실제 Microsoft Excel COM과 실제 S3 센서·PLC·램프 시험은 미실행입니다. 최종 제어 알고리즘 승인과 실제 장비 적용은 보류합니다.
