# 이미지 기반 회복 제어 · 평가용

GitHub 배포 소스 `4e9936ad6934b2efdbc73982fc33744e96375d55`와 최신 기본 브랜치 지침 `9f1cb65ac0f120445ebc7b796dae4171d9cc755d`에서 수정했습니다. 이전 코드·ZIP·실패한 후보의 시험 기록은 보존합니다. 제어 알고리즘 최종 승인과 실제 장비 적용은 보류합니다.

## 적용

슬라이싱 이미지 분석 후 **기본 알고리즘 → 계산 미리보기**에서 새 회복식을 사용합니다. 이미지가 없거나 `image_guard.enabled=false`이면 기존 계산을 유지합니다. 이미지가 있어도 실제 온도 급락과 이전 층 분사 계획이 일치하기 전에는 기존 출력·G·알파·베타 계산과 수동 출력·목표 변경 동작을 바꾸지 않습니다.

Excel 모드는 이번 **새 수동 계산시트**를 사용해야 합니다. `수동 계산시트 저장 / 사용`으로 저장하고 시트 `수동 테스트`, 입력 B13/C13/A13, 결과 D13, 목표 B5, 이미지 시작 BL13을 사용합니다. 이전 slice.1 / slice.2 시트의 참고열은 제어식을 변경하지 않습니다. 프로그램은 임의의 사용자 Excel 수식을 추가로 감싸거나 변경하지 않습니다.

## 급락과 회복

T_recoating은 현재 층 바인더 분사 전에 새로 측정하고, CSV는 해당 층 프린팅 후 저장됩니다. 따라서 급락은 **이전 층** 이미지의 전체 분사 계획과 대조합니다. 중앙 미도포·외곽 도포도 고려하며, 이미지 중앙과 센서 위치가 정확히 같다고 가정하지 않습니다. 현재 층 계획으로 이전 측정값을 설명하지 않습니다.

직전 3개 연속 온도의 범위가 1°C 이내이고, 그 최댓값보다 현재 온도가 4°C 이상 떨어지며 이전 이미지에 분사가 있으면 사건을 시작합니다. 슬라이싱은 예정된 분사 패턴이며 실제 분사·건조·방사율·온도를 독립적으로 증명하지 않습니다.

진입 직전 실제 저장 IR 3개의 중앙값 R과, 진입 당시 베타/G의 작은 쪽 이득을 고정합니다. 회복식은 다음과 같습니다.

`권장 절대 IR = R + K × (목표 − 온도 중앙값 − 예측층수 × 양의 온도 추세) + 이전 잔여 보정 I`

K는 진입 베타/G와 2%p/°C 중 작은 값입니다. 온도는 현재 포함 3개 관찰의 중앙값, 추세는 현재와 2개 전 온도의 차이를 2로 나눈 값입니다. 예측층수 기본 8은 회복 중 온도가 오르는 추세를 미리 반영해 감속하는 시험값입니다. 현재 IR에 보정량을 반복해서 더하는 방식이 아닙니다.

처음 2개 관찰은 증출력을 보류하고, 이후 회당 +1/−2%p로 제한합니다. 기존 계산이 더 큰 감출력을 제안하면 기존 감출력을 유지합니다. 원시 온도가 목표+데드밴드보다 높으면 중앙값이 늦게 반응해도 증출력하지 않습니다. 설정된 최대 증감과 0~100% 범위도 유지합니다.

잔여 보정 I는 냉각이 층마다 누적된다는 물리 가정이 아닙니다. 12개 관찰 이후에도 현재 포함 3개 온도가 모두 목표보다 낮고 예측 오차가 남으면 작은 보정을 추가합니다. 최종 출력의 증감·범위 제한이나 기존 감출력 때문에 명령을 따라가지 못하면 양의 누적을 중단합니다. 원시 온도가 높아지면 I를 0을 향해 줄입니다. I는 0과 기준 IR의 출력 여유 사이로 제한합니다. 이번 출력은 이전 I로 계산하고, 갱신 I는 다음 관찰에서 사용합니다.

실측 온도가 목표 ±0.5°C이고, 추세가 0.25°C/층 이내이며 저장 IR 변화가 1%p 이내인 상태가 5개 연속이면 기존 계산으로 복귀합니다. IR 변화 허용치는 예측식이 측정 잡음을 확대하는 점을 고려한 잠정값입니다. 최대 회복은 120개 관찰이며, 미회복 시 12개 관찰에 걸쳐 기존 권장값을 섞고 출력 한도도 점진 복귀시킵니다. 같은 사건으로 기준 출력이나 기한을 계속 갱신하지 않습니다. 이미지 누락은 진행 중 회복을 취소하지 않습니다.

회복·복귀 중에는 진행 중 반응 평가와 불완전한 학습 묶음을 버리고 G·알파·베타 갱신을 격리합니다. 원래 알파의 역할은 G 자동 학습이며 잔여 보정의 적분 계수로 바꾸지 않습니다. 사건 후 이미지 전환·누락 경계와 이후 대기층+3개 관찰을 지나면 기존 학습을 재개합니다. 영구적으로 미확인인 이미지 때문에 학습을 계속 중지하지 않습니다.

## 수동시트 설정

`이미지 억제 설정`에서 잠정값을 편집할 수 있습니다. 기본은 절대 기준 회복입니다. 제한식 비교 모드와 분사 중 학습 제외는 개발 비교용이며 기본 해제 상태입니다. 분사 중 학습 제외를 켜면 알려진 분사 구간에서 계수를 유지하는 대신 실제 이득 변화에 적응하지 못할 수 있습니다.

BL:BW는 이미지 입력, D는 최종 권장값, CQ는 기존 계산값, CL은 0 일반 / 1 초기 보류 / 2 회복 / 3 점진 복귀입니다. DC는 고정 기준 IR, DD는 진입 이득, DH는 예측 오차, DI/DJ는 이번/다음 잔여 보정, DL은 복귀 비율입니다. 자동 연결에서는 이전 행 전체를 계산값으로 고정하고 원본 XLSX를 저장하지 않습니다.

## 검증 해석

300층 합성 모델은 처음 바인더 투입 후 급락하고, 같은 면적의 프린팅 중 온도가 회복되는 상황을 주 조건으로 사용합니다. 냉각이 무한히 중첩되는 모델을 쓰지 않습니다. 일정한 냉각 영향을 오래 유지하거나 갑자기 제거하는 조건은 별도 스트레스 시험입니다. 이득·지연·냉각값은 실제 장비에서 식별한 값이 아닙니다.

대표 모델에서 센서 최고 온도는 69.37→66.34°C, 평균 절대 오차는 1.645→1.069°C였습니다. 새로 예약한 108개 조건에서는 기존보다 센서 과열이 커진 경우가 없었고, 평균 오차는 3개 조건에서 최대 0.052°C 증가했으며 저온 하락 폭은 27개 조건에서 최대 0.449°C 증가했습니다. 일정 냉각 후 제거 시험도 과열이 7.91→4.91°C로 줄었습니다. 모든 조건과 실패한 개발 후보를 함께 보존하며 보편적 성능 보장을 하지 않습니다.

실제 Microsoft Excel 데스크톱 PC가 없어 Excel COM 연동은 미검증입니다. LibreOffice 오프라인 재계산·과거 행 고정 시험과 구분합니다. 실제 센서·PLC·램프와 장시간 운전도 미검증입니다. 정상 범위의 오래된 센서값과 방사율 변화는 CSV·슬라이싱만으로 독립 판별할 수 없습니다. 센서 편향 시험에서는 모델의 실제 온도도 함께 비교해야 합니다.
