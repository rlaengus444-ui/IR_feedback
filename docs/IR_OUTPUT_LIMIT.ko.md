# IR 출력 상한과 검증 범위

`2026.11.03-ir-cap.1`에서는 연결 전에 최대 IR 출력값을 0~100%로 지정합니다. 기본값은 100%이며 연결 중 고정됩니다. 설정은 `%LOCALAPPDATA%/IRFeedback/ir-output-limit.json`에 저장됩니다. 기본 알고리즘과 Excel 알고리즘 모두 이 상한과 기존 1회 최대 5%p 증감 제한을 적용합니다. 기본 알고리즘의 유효 상한은 JSON 알고리즘 설정의 최대값과 사용자 상한 중 작은 값이며, 설정된 최소값이 유효 상한보다 크면 거부합니다.

현재 IR 설정이 상한보다 높으면 상한까지 갑자기 낮추지 않고 Save를 대기합니다. 대기 중에도 CSV 수신과 그래프는 유지합니다. Excel은 원시 수식 결과가 0~100%인지 먼저 검증한 후 상한과 5%p 제한을 적용합니다. 원본 수식과 확정된 이력은 바꾸지 않고 현재 IR 입력에는 실제 설정값을 사용하므로, 워크북 알고리즘 자체가 상한을 고려한다고 해석해서는 안 됩니다.

원본 창은 HWND로 접근하여 브라우저 등 다른 창이 전면에 있을 때 포커스를 빼앗지 않도록 설계했습니다. 실제 Windows GUI 및 네이티브 동작과 최소화 상태의 이번 버전 시험은 대기 중입니다. 잠금 화면, 절전, 관리자 권한 불일치, 실제 장비와 Excel COM은 미검증입니다. 온도계 비활성 값 -1은 차단하지만 정상 범위의 오래된 센서값은 CSV만으로 구별할 수 없습니다. 제어 알고리즘 최종 승인과 실제 장비 적용은 보류합니다.
