# 첫 탭 경로에서 슬라이싱 이미지 자동 분석

`2026.10.30-csv-wait.2` 검증 후보입니다. 입력할 수 없는 일반 텍스트 표시 칸(STATIC)과 읽기 전용 입력칸(EDIT)을 모두 지원합니다. 실제 장비의 커스텀 표시 칸 종류는 사진만으로 확인할 수 없습니다. 기존 수동 ZIP·이미지 선택과 중앙 반경·DPI 분석, 제어 수식, 계산시트 두 종류, 설정 변경 시 연결 유지와 CSV·두 PNG 저장은 유지합니다.

## 사용

1. BJT 첫 탭(Home)에 슬라이싱 이미지 경로를 표시해 둡니다. 외부 모듈에서 해당 BJT 실행 창을 선택합니다.
2. 슬라이싱 이미지 탭의 **첫 탭 경로 지정 (5초)**을 누르고 경로 글자 위로 마우스를 옮깁니다. BJT를 클릭하거나 입력할 필요는 없습니다. 미리보기에 표시된 폴더가 맞으면 **예**를 선택합니다.
3. **첫 탭 경로에서 자동 불러오기**를 선택하고 중앙 반경 mm, X/Y DPI, 분사 색상과 기준값을 확인합니다. 기본 DPI는 400×400, 분사 색상은 흰색입니다.
4. **파일명 기준 번호**와 **첫 파일 대응 층**을 지정합니다. 기준 번호 1, 대응 층 1이면 001.png는 1층, 501.png는 501층입니다. 폴더에 501번만 있어도 1층으로 당기지 않습니다. 000.png가 1층이면 기준 번호를 0으로 지정합니다.
5. 경로 지정은 완료/실패 안내와 자동 분석 상태를 별도로 표시합니다. 실패하면 확인 창과 상태 기록·IR-module-error.log에 이유를 남깁니다. 이전에 확인한 경로는 실패·취소로 지우지 않습니다.
6. 연결하면 지정한 표시 칸의 경로에서 같은 폴더의 지원 이미지 전체를 불러와 분석합니다. 하위 폴더를 임의로 합치지 않습니다. 자동 모드의 층 배정은 파일명 끝 숫자를 사용합니다. 자동 경로와 분석 상태는 같은 탭에 표시됩니다.

첨부된 원본 코드에는 경로를 표시하는 사용자 컨트롤의 구현이 없어 처음에는 표시 칸을 직접 지정합니다. 표나 임의의 다른 경로를 자동으로 추측하지 않습니다. 지정한 칸이 다시 생성되거나 BJT 실행 창이 바뀌면 다시 지정해야 합니다. 정상적인 탭 이동 뒤에는 유지된 표시 칸을 읽으며, 탭을 자동으로 전환하지 않습니다. 커스텀 그리기 등으로 텍스트가 외부에 노출되지 않는 칸은 지원하지 않습니다.

## 프린팅 중 변경

첫 탭의 경로는 CSV와 독립된 작업자가 감시합니다. 경로가 다른 이미지 폴더로 바뀌면 IR 적용을 대기시키고 전체 이미지를 다시 분석합니다. 복사 중인 파일은 안정된 목록을 확인한 뒤 분석하며, 분석 중 경로가 다시 바뀌면 오래된 결과를 적용하지 않습니다. 현재 표시 파일명이 001→002로 바뀌어도 같은 폴더의 이미지셋은 매번 재분석하지 않습니다.

같은 폴더 안의 파일 추가·삭제·변경도 감지합니다. 크기·수정 시각이 같은 덮어쓰기는 백그라운드 내용 검사와 계산 전 현재·이전 이미지의 SHA-256 검사로 확인합니다. 동일 경로에서 내용이 바뀌면 새로 분석하되, BJT에서 실제로 이미지를 다시 불러온 뒤 **같은 경로 재불러오기 확인**을 눌러야 IR 적용을 이어갑니다. 파일 경로와 해시만으로 BJT가 이미 메모리에 올린 이미지의 바이트까지 증명할 수는 없습니다.

자동 모드는 연결 전에 선택합니다. 연결 중에도 중앙 반경·DPI·층 대응과 경로 표시 칸을 바꿀 수 있습니다. **분석 취소**는 자동 적용을 대기시키며 **다시 분석**으로 재개합니다. 자동 모드를 끄고 연결하면 기존 수동 ZIP·이미지 선택을 그대로 사용합니다. ZIP 내부 항목과 BJT가 해제한 경로 사이의 대응을 추측하지 않으므로 자동 입력은 폴더 또는 개별 이미지 경로만 지원합니다.

## CSV와 계산 시점

CSV는 리코팅 순간이 아니라 층 완료 뒤에 기록됩니다. 따라서 새 이미지 불러오기와 변경 감지에 CSV 도착을 기다리지 않습니다.

이미지 데이터를 사용하는 Excel 모드에서는 다음 조건을 확인한 뒤 계산합니다.

- 이미지 변경을 감지한 이후에 새로 측정한 리코팅 온도인지 확인합니다. CSV 행이 늦게 생성됐더라도 교체 전에 측정된 온도는 새 이미지셋의 계산에 쓰지 않습니다. 초 단위 시각의 모호한 경계도 제외합니다.
- 실제 층의 `ImgSlicing` 전체 경로와 분석한 해당 층 파일이 일치해야 합니다. 파일명만 같은 다른 폴더는 허용하지 않습니다.
- 기본값을 유지해 Save하지 않는 층과 기준층도 계산·학습 전에 이미지 내용과 CSV 경로·리코팅 시각을 확인합니다. 확인되지 않은 이전 층과 교체 전 무분사 누적값을 새 이미지의 과거 이력으로 채우지 않습니다.
- 새 이미지는 완성된 데이터만 교체합니다. 계산 이력을 초기화하고 유효 기준층을 확인한 뒤 다른 새 층부터 이어갑니다. 대기 중 관찰이나 같은 층의 수정 행을 나중에 재사용하지 않습니다.

대기 중에도 연결·온도 그래프·CSV 기록은 유지합니다. 본문에서 말하는 대기는 이미지에 의존하는 Excel 계산에 적용합니다. 이미지 입력을 사용하지 않는 내장 알고리즘과 Excel은 기존 계산을 유지합니다. 온도 -1, CSV 작업·시각·신선도 보호와 입력/Save 결과 불명확 시의 기존 중단 처리는 유지합니다.

## 검증 범위

이 기능은 오프라인 파일·모의 세션과 소유한 합성 Windows 창으로 검증합니다. 실제 장비 첫 탭의 경로 표시 칸, Excel COM, 센서·PLC·램프와 장시간 프린팅은 미검증입니다. 최종 제어 승인과 실제 장비 적용은 계속 보류합니다. 최종 후보의 실행 결과와 독립 검토는 별도 검증 기록에 남깁니다.

## csv-wait.2의 화면 수정

CSV 갱신 대기 상태를 UI에 표시하지 못해 화면 갱신과 경로 지정 결과 처리가 멈추던 누락을 수정했습니다. 실제 Tk 갱신 루프에 CSV 대기와 후속 경로 지정 결과를 넣는 회귀시험을 추가했습니다. 이전 295개 시험은 이 GUI 연동 경로를 확인하지 못했습니다. 이번 수정은 경로를 읽는 Win32 방식, CSV/이미지 대응 검증, 제어 수식이나 입력·Save 보호를 변경하지 않습니다.

사진에 경로가 말줄임표로 보이더라도 실제 텍스트가 잘린 것인지는 별개입니다. 화면상 말줄임만 적용되고 전체 텍스트가 노출되는 표시는 읽을 수 있습니다. 실제로 읽은 문자열 자체가 생략되어 있으면 임의로 경로를 복원하지 않고 대기합니다. 사진 속 장비의 바인딩 성공은 아직 확인하지 못했습니다.
