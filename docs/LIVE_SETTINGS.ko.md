# 설정 변경 시 연결 유지와 CSV·플롯 자동 저장

`2026.10.29-reconnect.3` 평가 후보입니다. 내장 제어 수식과 외부 Excel 계산시트 두 종류, 이미지 분석·교체, BL13 기본값과 CSV 작업 식별은 유지합니다.

## 설정 변경 시

BJT의 IR·파라미터·시퀀스 설정이나 해당 입력창이 바뀌면 외부 모듈은 **연결을 유지하고 IR 적용만 대기**합니다. 온도 CSV 조회, 그래프 기록, 목표값 예약과 이미지 교체는 계속 사용할 수 있습니다. 미저장 편집값을 자동 저장하거나 취소하지 않습니다.

읽기 전용 확인으로 저장 설정과 Sequence 화면의 전체 입력값이 일치하는지 확인합니다. 설정 파일을 UI 확인 전후에 읽어 도중 변경을 검사하고, 1초 이상 떨어진 두 확인에서 같은 설정·입력창을 확인해야 새 기준을 채택합니다. 재확인 중에는 탭을 자동으로 열거나 IR 입력·Save를 실행하지 않습니다. 새로 만들어진 입력창이 현재 화면에서 확인되지 않으면 해당 영역을 확인할 때까지 연결된 대기 상태를 유지합니다.

확인이 끝나면 이전 권장값을 폐기하고 내장 제어 또는 격리된 Excel 계산 이력을 초기화합니다. 첫 유효 관찰은 기준값으로 읽고, 그다음 새 층의 온도부터 새 실제 IR 설정을 기준으로 계산합니다. 대기 중 쌓인 과거 관찰이나 같은 층의 수정값을 뒤늦게 적용하지 않습니다. 설정과 이미지가 함께 바뀌면 두 확인을 모두 만족해야 합니다. 이 모듈이 성공 확인한 Save는 외부 변경으로 취급하지 않습니다.

기존의 온도 -1 차단, CSV/작업/층·시각/신선도 검사, 대상 PID·장비 식별과 출력 범위 보호는 유지합니다. IR 편집 또는 Save가 실행됐을 가능성이 있거나 결과가 불명확하면 기존처럼 종료하며 자동 재시도·원복·히터 정지 명령을 보내지 않습니다. 설정 변경 대기는 이러한 오류를 무시하는 기능이 아닙니다.

## 연결 종료 시 저장

해제 버튼, 오류로 인한 종료 및 프로그램 닫기 때 관찰한 전체 데이터를 다음 세 파일로 저장합니다. 작업이 바뀌는 경우에도 이전 구간을 보관합니다.

- 기존 UTF-8 BOM CSV: 온도·관찰한 IR 설정·Save 성공값을 구분하는 전체 7열.
- `…_temperature.png`: 전체 관찰 층의 T_recoating 온도.
- `…_ir.png`: 관찰한 IR 설정선과 성공이 확인된 Save 점.

두 PNG는 1600×900, 150 dpi이며 최근 100층 밖의 관찰도 포함합니다. 미확인 값과 빠진 층을 연결해 가짜 곡선을 만들지 않습니다. 온도 그림의 목표선은 해당 구간을 보관할 때의 목표값이며 과거 목표 이력이 아닙니다. IR 그래프는 램프 실측 출력이 아닙니다.

기본 저장 위치는 실행 파일 옆 `records`, 쓰기 실패 시 `%LOCALAPPDATA%/IRFeedback/records`입니다. 정상적으로는 같은 CSV 이름을 기준으로 같은 폴더에 저장합니다. 파일 쓰기는 별도 작업에서 진행하며 경로와 결과는 상태 기록에 남깁니다.

CSV나 PNG 하나가 실패해도 이미 저장한 파일은 지우거나 덮어쓰지 않습니다. 전체 관찰과 목표값의 불변 복사본을 유지하고 실패한 파일만 다시 시도합니다. 재시도 폴더가 달라 일부 PNG가 다른 폴더에 저장되면 각 경로를 기록합니다. 종료 시 실패한 항목은 다른 폴더를 선택할 수 있으며 취소하면 기록과 창을 유지합니다. 기존 종료 관찰 마감 시점은 재시도 중에도 바뀌지 않습니다.

## 검증 범위

소프트웨어 모의 시험과 정확한 Windows 후보 ZIP의 시험·독립 검토 결과는 해당 후보의 검증 기록을 따릅니다. 실제 Excel COM, M1/S3 센서·PLC·램프 출력과 장시간 프린팅 시험을 대신하지 않습니다. 최종 제어 알고리즘 승인과 실제 장비 적용 보류는 유지합니다.
