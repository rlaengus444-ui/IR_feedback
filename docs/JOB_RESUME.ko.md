# 프린팅 재시작과 컨트롤러 자동 재연결

`2026.11.11-job-resume.1` 평가판은 연결 버튼으로 시작한 관측 세션 안에서 프린팅 작업이 바뀌어도 확인 후 IR 피드백을 자동 재개합니다. 장비 지원은 M1·S3입니다.

프린팅 중지 시 관측은 유지하고 IR 적용을 대기합니다. 다시 시작하면 새 AutoPrint 시작 기록의 파일 식별·바이트 위치와 첫 층/시각, 일치하는 Monitoring CSV, 새 유효 온도와 AUTO/RUNNING 상태를 확인합니다. 같은 작업 근거가 1초 이상 간격으로 두 번 확인되고 화면 입력 전체와 저장 설정도 두 번 일치해야 새 작업을 승인합니다. 이전 계산과 Excel 이력을 초기화하며, 첫 관찰은 기준으로 소비하고 더 높은 새 완료 층부터 적용합니다. 행 생성이 늦으면 생성될 때까지 기다립니다.

컨트롤러가 종료되면 같은 실행 경로·장비의 창을 재검색합니다. 후보가 하나일 때 새 PID/HWND로 읽기 연결 후 설정 전체와 새 기준/더 높은 새 층을 확인하고 자동 재개합니다. 화면의 PID와 상태 기록도 갱신합니다. 후보가 없거나 여러 개면 관측 상태로 재검색합니다. 재시도 간격은 2·5·15·30·60초입니다. 기존 논리 세션·층별 적용 시도 기록과 기록 데이터는 유지합니다.

같은 초에 동일한 시작 문구가 다시 기록되어도 서로 다른 작업으로 식별합니다. 이전 작업의 계산은 새 작업에 사용하지 않습니다. 계산 직후 작업이 바뀌는 경합을 막기 위해 native 검증, IR 입력 직전과 Save 직전에 원본 로그의 검증된 바이트와 이후 추가 기록을 다시 확인합니다. 로그 누락·부분 기록·교체·새 작업·중단·층 진행 불일치는 해당 적용을 취소합니다. 파일 확인과 외부 Save는 원자적 거래가 아니며 실제 장비 시험을 대신하지 않습니다.

작업이 바뀌면 기존 이미지 분석은 보존하지만 이미지 참고값을 미확인으로 보냅니다. 현재 작업과 동일한 이미지임을 확인한 후 슬라이싱 이미지 탭의 **현재 작업에 이미지 적용**을 누르세요. 재분석 없이 같은 분석을 현재 작업에 다시 연결할 수 있습니다. 작업 식별이 없는 동안에는 적용 요청을 받지 않으며, 이전 작업에서 시작한 분석 결과를 새 작업에 자동 적용하지 않습니다. 같은 작업의 PID 교체에는 이미지 범위를 유지합니다. 수동 Excel 시트는 이미지 미확인 시의 기존 온도 기반 분기를 사용합니다.

목표 온도, 연결 중 변경 가능한 IR 상한, 층당 최대 변화 제한, 수동 이미지 불러오기, 최근 100층/전체 그래프, 연결 종료 시 CSV·온도/IR PNG 저장은 유지합니다. Save 결과 불명확, Excel 작업 종료 미확인, 계산·설정·프로토콜 무결성 오류는 재시작으로 자동 해제하지 않습니다. 임의의 모든 오류에서 출력을 다시 쓰는 기능은 아닙니다.

CSV/UI 조회·Excel 계산·재검증 중 시간이 지나면 아직 입력을 시작하지 않은 권장값만 폐기합니다. 같은 작업·설정·목표·상한·이미지 범위에서 계산이 이미 확정된 경우 연결과 실제 입력 이력을 유지하고 다음 새 층에서 자동 계산·적용을 이어갑니다. 만료된 층을 다시 시도하지 않습니다. 미확정 계산이나 제어 세대 변경은 기존 초기화 조건을 따릅니다. 파일 수정 시각과 완료 행 시각의 5초 신선도 제한은 유지하며, IR 입력 직전에는 2초의 남은 시간을 추가 확인합니다. 입력 후 결과가 불확실한 경우에는 보호 대기를 유지합니다. 모든 필드의 조회·저장 확인은 유지하고, 필드 읽기 내부와 중복되는 종류 확인만 줄였습니다.

Save는 한 번만 요청합니다. 원본 UI가 저장 처리로 잠시 바쁘면 같은 PID/창의 응답만 최초 대기 시간을 포함해 최대 1초 동안 확인합니다. 응답 후 실제 IR 읽기와 저장 파일의 IR·기타 파라미터 일치 검사는 그대로 수행합니다. 완료를 확인하지 못했거나 값·창 식별이 달라지면 기존 불확실성 보호를 유지하며 Save를 다시 보내지 않습니다.

검증은 단위 시험과 소유한 Windows 모의 컨트롤러로 진행합니다. 실제 BJT·센서·PLC·램프 및 Excel COM 시험, 알고리즘 최종 승인과 실제 장비 적용 승인은 별도이며 보류 상태입니다. 실제 검증 결과는 해당 릴리스의 증거 파일과 검토 기록을 확인하세요.
