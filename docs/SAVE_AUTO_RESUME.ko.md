# Save 지연 후 자동 재개

`2026.11.11-save-resume.1`은 응답 지연을 이후 층 전체의 영구 차단으로 처리하지 않습니다. M1·S3가 대상입니다.

기존 Save 버튼의 알림을 한 번 동기적으로 전달하고, 외부 모듈이 만든 전용 도우미에서 실제 처리 반환을 추적합니다. 호출 측의 5초 대기 시간이 지나도 해당 도우미와 요청 기록을 보존하며 CSV 수신·그래프를 계속합니다. 도우미가 끝나기 전에는 추가 Save나 제어 재준비를 시작하지 않습니다.

동일 요청·PID·창·프로세스 생존 구간의 처리 완료 증거, 도우미 종료와 정상 응답을 확인한 뒤 화면의 전체 Sequence 입력과 실제 저장 파일을 두 번 대조합니다. 요청한 IR과 다른 설정이 그대로 저장된 경우에만 현재 실제 저장 IR을 기준으로 새롭고 더 높은 완료 층을 계산합니다. 이전 층의 Save·권장값을 재전송하거나 과거 성공점으로 소급 기록하지 않습니다. 불확실한 계산 이력은 한 번 초기화하며 알고리즘의 일반 초기 관찰 규칙은 유지합니다.

목표 온도, 연결 중 IR 상한 변경, 층당 최대 5%p 제한, 이미지 입력, CSV·두 PNG 저장과 프린팅 재시작·PID 자동 재연결 기능은 유지합니다. 새로운 작업·센서 무효·미저장 편집·다른 설정 변경에는 각각의 확인 조건을 적용합니다. 완료 증거가 없거나 손상됐거나 도우미가 비정상 종료된 경우까지 저장 성공으로 추정하지 않습니다. 원본 앱이 계속 응답하지 않거나 설정을 검증할 수 없으면 관측과 확인 대기를 계속하며 IR 적용을 보장할 수 없습니다.

실제 BJT·센서·PLC·램프 및 Excel COM 시험은 미실행입니다. 프로그램·Windows 합성 시험 결과와 실제 장비 검증은 구분하며 최종 알고리즘 승인과 실제 장비 적용 보류를 유지합니다.
