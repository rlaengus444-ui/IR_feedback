## Windows 배포 검증

GitHub Actions의 `Validate slice candidate` 작업은 최종 ZIP에서 추출한 내장 Python으로 전체 시험을 실행하고, 실제 EXE가 생성한 Python 프로세스와 주 창을 확인합니다. 시험 의존성은 배포 ZIP 밖에 두며, 검증 전후 ZIP 해시가 동일해야 합니다. 실행 결과와 해당 소스 커밋·해시는 별도 결과 파일에 남깁니다. 실행을 시작했다는 사실만으로 검증 통과로 기록하지 않습니다.

Microsoft Excel이 있는 환경에서는 실제 COM을 이용해 이미지 입력, 누락값의 빈 셀 처리, 초기화·재열기와 과거 행 고정을 검증합니다. 설치된 Excel로 이 시험을 실행하지 못하면 `release_ready=false`로 기록하고 정식 배포 검증을 미완료로 남깁니다. PowerShell 구문 검사·mock 시험·LibreOffice 결과를 실제 Excel 연동 시험으로 바꾸어 표기하지 않습니다.

## 남은 한계와 보류

실제 프린팅 작업의 슬라이싱 ZIP은 아직 제공받지 않아 합성 이미지로 검증했습니다. 실제 센서·PLC·램프 출력과 장시간 열 제어 안정성은 미검증입니다. 정상 범위의 오래된 센서값은 CSV만으로 감지할 수 없습니다. 도포 계획은 실제 분사·센서 위치·건조 완료를 보장하지 않습니다.

기존 제어 수식은 유지하며 새 이미지 데이터는 참고 입력입니다. **제어 알고리즘 최종 승인과 실제 장비 적용은 계속 보류합니다.** CLI Sol 호출의401인증 실패와 별도 협업 도구에서 성공한 Sol Max 검토는 구분해 기록했습니다. 누락된 사전 설계 검토를 사후 검토로 소급하지 않습니다. 배포 후보의 최종 Sol 검토와 필수 Windows·Excel 검증이 완료되기 전에는 정식 배포본을 교체하지 않습니다.
