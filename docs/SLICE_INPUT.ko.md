# 슬라이싱 이미지와 수동 계산시트

GitHub `main`의 `4686ac2b3b5b67aa0f0cfe76f06facd7459d28e7`을 기준으로 작성한 소스 변경입니다. 기존 `2026.10.27-csv.6` EXE에는 이 기능이 포함되어 있지 않습니다. 현재 작업은 오프라인 검증용이며, 제어 알고리즘의 최종 승인과 실제 장비 적용은 보류합니다.

## 이미지 입력

1. 연결하기 전에 **슬라이싱 이미지** 탭에서 **ZIP 불러오기** 또는 **이미지 전체 선택**을 누릅니다. 여러 이미지는 파일 선택 창에서 Ctrl+A로 선택할 수 있습니다.
2. **중앙 반경 mm**에 분석할 원의 반경을 입력합니다. X/Y DPI 기본값은 각각 400이며 변경할 수 있습니다. 분사 색상 기본값은 흰색입니다.
3. 첫 파일이 대응하는 실제 층 번호를 확인합니다. 기본 **파일명 숫자** 방식은 파일명 끝 숫자를 읽고 번호 사이의 누락을 유지합니다. 예를 들어 001, 003은 첫 대응층이 1일 때 1, 3층이며 2층은 미확인입니다. 번호가 없는 파일은 실제 순서를 확인한 뒤 **정렬순 연속**을 선택합니다.
4. 입력이나 설정을 바꾸면 이전 분석값이 즉시 무효화되고 자동 재분석됩니다. 분석이 끝난 후에만 연결할 수 있습니다. 연결 중에는 이미지와 분석 설정을 바꿀 수 없습니다.

원의 물리 크기는 각 축의 DPI로 환산하며 픽셀 중심이 원 안에 있는지를 계산합니다. 반경이 이미지 밖으로 나가거나 이미지 크기가 서로 다르면 거부합니다. PNG/BMP/TIF/TIFF/JPEG의 단일 이미지, 8비트 회색조·RGB·팔레트 등을 지원합니다. 16비트 정수·실수형 및 다중 페이지 이미지는 잘못된 판정을 피하기 위해 거부합니다.

**중앙 도포율**은 해당 원 안에서 분사 기준을 초과한 픽셀 비율, **중앙 평균강도**는 선택한 분사 색상을 기준으로 정규화한 평균 밝기, **전체 도포율**은 이미지 전체의 분사 픽셀 비율입니다. 기준값 기본 0은 흰색 분사 모드에서 검정 이외의 모든 픽셀을 포함합니다. 투명 영역은 분사가 없는 영역으로 처리합니다. JPEG 압축 잡음이나 회색 배경이 있으면 기준값을 확인하세요.

전체 데이터는 **전체 분석 CSV 저장**으로 저장합니다. 표에는 처음 1,000개만 표시하지만 CSV에는 모두 포함됩니다. 파일에는 반경·DPI·기준값·분석 데이터 해시도 기록됩니다. 이미지는 연결 전에 한 번 분석하며, 층별 계산에서는 저장된 수치를 조회합니다.

## 수동 계산시트

**수동 계산시트 저장 / 사용**을 누르면 편집 가능한 XLSX를 저장하고 Excel 알고리즘의 셀 설정을 채웁니다. 이미지 분석이 완료되어 있으면 해당 데이터도 시트에 넣습니다. 이미지 선택을 지우면 빈 수동 계산시트를 만들 수 있습니다. 분석값을 포함하는 시트는 최대 3,000층 범위를 지원하며, 전체 분석 결과는 CSV로 저장할 수 있습니다.

| 설정 | 값 |
| --- | --- |
| 시트 | 수동 테스트 |
| 온도 / 현재 IR / 권장 IR | B13 / C13 / D13 |
| 목표 / 실제 층 번호 | B5 / A13 |
| 이미지 시작셀 | BL13 |

| 열 | 입력 데이터 |
| --- | --- |
| BL | 현재 층 이미지 유효 1/0 |
| BM:BO | 현재 층 중앙 도포율·중앙 평균강도·전체 도포율 (%) |
| BP | 이전 층 이미지 유효 1/0 |
| BQ:BS | 이전 층 중앙 도포율·중앙 평균강도·전체 도포율 (%) |
| BT | 이전 층까지 알려진 연속 전체 무분사 이미지 수 |
| BU:BW | 반경 mm·X DPI·Y DPI |

기존 G·알파·베타와 권장출력 D열 수식은 유지합니다. BX:CC의 새 수식은 이미지 계획과 급락의 관계를 살펴보는 **참고 예시**입니다. 기본 알고리즘의 권장출력을 자동으로 보정하지 않습니다. 사용자가 수식을 바꿀 때 이 열과 BL:BW를 참조할 수 있습니다. 보조 설정의 4°C·3층은 시험용 참고값이며 실제 건조나 제어 안정성을 검증한 값이 아닙니다.

T_recoating은 리코팅 직후, 현재 층 바인더 분사 전에 새로 측정한 값입니다. 이전 층 분사의 영향은 BP:BS와 대조하고 현재 층 계획 BL:BO와 구별해야 합니다. 이미지는 예정된 도포 패턴이며 실제 분사 실행·센서 위치·건조 완료를 증명하지 않습니다. 중앙 도포율 0이어도 외곽에 도포가 있을 수 있습니다. 누락 이미지는 유효 0과 빈 비율로 전달하며, 무분사 0으로 대체하지 않습니다.

Excel 연결 시에는 저장된 이미지 입력을 지우고, 연결 후 새로 받은 관찰의 실제 층 번호에 해당하는 분석값을 다시 넣습니다. 기존 수동시트에서는 **이미지 시작셀**을 비워 두면 기존 입력 방식을 유지합니다. 선택한 원본 XLSX는 수정하지 않습니다.

소스에서 이미지 분석을 실행하려면 Pillow가 필요합니다. 템플릿 빌드·테스트에 사용하는 openpyxl은 앱의 시트 저장 기능에는 필요하지 않습니다. 자동 Excel 계산에는 기존과 동일하게 Windows의 Microsoft Excel 데스크톱이 필요합니다. LibreOffice를 이용한 오프라인 교차계산은 Microsoft Excel COM 및 실제 센서·PLC·램프 검증을 대신하지 않습니다.
