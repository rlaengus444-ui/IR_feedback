# M1 화면이 가려진 상태의 복구와 기록 파일

`2026.11.09-m1-recovery.1` 평가판입니다. 지원 장비는 **M1·S3**이며 **M2는 아직 지원하지 않습니다**. M2를 M1로 선택해 적용하지 마세요.

## M1 로그에서 확인한 문제

첨부 로그의 16:22:59 이후에는 복구 검사 중 입력 항목의 표시 상태가 바뀌었다는 메시지와 `Sequence Save button is not visible`이 반복됩니다. 기존 코드는 복구할 때 화면에 보이는 Sequence 항목을 다시 수집하므로, Sequence가 가려진 상태에서는 설정을 재확인하지 못하고 IR 적용 대기를 계속할 수 있었습니다. 화면이 왜 가려졌는지와 최초 대기 원인은 이 로그만으로 확정할 수 없습니다.

이 버전은 최초 연결 때 확인한 Sequence 영역과 장비·운전 상태 표시를 다시 검증하고, 그 영역의 현재 입력 전체와 저장 파일이 안정적으로 일치하는지 두 번 확인합니다. 다른 탭을 열거나 다른 프로그램을 사용하는 동안에도 이 확인을 시도하며, 복구 과정에서 탭을 열거나 포커스를 가져오거나 IR을 저장하지 않습니다. 복구 완료 후에도 기준 관찰과 다른 유효한 새 층을 기다립니다.

Save·IR 또는 필수 입력 자체가 숨겨지거나 비활성화된 경우, 미저장 편집, 설정 파일 저장 중, 다른 작업·장비, 오래되거나 잘못된 센서/CSV, 불확실한 Save에는 기존 대기·차단 조건을 유지합니다. `IDLE`, `MOVING`, `AUTO CLEANING`은 확인된 `AUTO/RUNNING`이 아니므로 해당 상태에서 출력을 강제로 적용하지 않습니다.

## 자동 저장 위치와 이름

연결 종료 또는 프로그램을 닫을 때 전체 관찰 CSV와 두 PNG를 자동 저장합니다. IR 적용 **대기**는 연결 종료가 아니므로, 대기 메시지만으로 자동 저장이 시작되지는 않습니다. 작업 변경 시 이전 기록은 메모리에 보관하고 연결 종료·프로그램 닫기 때 함께 저장합니다. 수신한 행이 없으면 파일을 만들지 않습니다.

| 순서 | 위치 |
| --- | --- |
| 기본 | 압축을 해제한 `IRFeedback.exe` 옆 `records` 폴더 |
| 기본 위치 쓰기 실패 시 | `%LOCALAPPDATA%\IRFeedback\records` |

CSV와 각 PNG는 독립적으로 저장 위치를 대체할 수 있습니다. 상태 기록의 `CSV·플롯 자동 저장 완료`, `온도 플롯 PNG`, `IR 플롯 PNG`에 각각 표시되는 전체 경로를 확인하세요. 저장하지 못한 기록은 메모리에 보존하며, 종료 시에는 다른 폴더를 선택할 수 있습니다.

새 자동 저장 이름은 장비와 **저장 시각(PC 현지 시간)**을 사용합니다.

- `M1_2026-11-09_18-30-00.csv`
- `M1_2026-11-09_18-30-00_온도.png`
- `M1_2026-11-09_18-30-00_IR.png`

이름이 겹치면 `_02`, `_03`을 붙여 기존 파일을 보존합니다. 부분적으로 저장에 성공한 뒤 재시도해도 성공한 파일을 다시 쓰거나 이름을 바꾸지 않습니다. 수동 **CSV 저장**은 기존 저장 대화상자에서 직접 경로와 이름을 선택합니다.

## 검증 범위

코드 검토, 합성 Windows 창·CSV·설정 파일 시험과 패키지 검증 결과는 배포 기록에 따로 남깁니다. 실제 Excel COM·M1/S3·센서·PLC·램프·장시간 운전의 검증을 의미하지 않습니다. 제어 알고리즘 최종 승인과 실제 장비 적용은 보류합니다.
