# CSV 외부 IR 모듈 검증 기록

버전 `2026.10.27-csv.2`, 검증일 2026-10-27. 원본의 코드·실행파일·설정에 추가 변경을 적용하지 않았습니다.

## 이번 추가 기능

연결 중 목표 온도 변경은 다음 새 관찰부터 적용되며 현재 행 재계산이나 즉시 저장을 일으키지 않습니다. Excel 옵션은 입력과 수식 결과 셀을 사용하고 기존 파일은 수정하지 않습니다. 독립 Excel 인스턴스에서 목표를 두 번 변경하며 랜덤 80층의 결과를 비교해 모두 일치했습니다. 실제 Excel·제품 세션·CSV·native 어댑터를 가상 M1 창과 결합한 별도 시험에서 표 접근 0회와 Save 1회를 확인했습니다. 지원하지 않는 수식·연결·잘못된 결과와 시간 초과는 제어를 중단합니다. 층별 그래프는 연결 이후 수신 값과 Save 성공값을 구분하며 제품의 제어 경로에 관여하지 않습니다.

## 변경과 범위

온도와 층 입력을 Process DataGridView에서 Monitoring CSV로 교체했습니다. 컴파일된 브리지에서 표 읽기·스크롤 클래스를 제거했고 dispatcher에는 표 접근이나 Process 전환 명령이 없습니다. 온도 수신 과정에는 UI Automation/MSAA를 사용하지 않습니다. 자동 적용 준비와 기존 Sequence의 입력·Save 확인에만 개별 컨트롤 식별과 native 메시지를 사용합니다.

CSV는 층 인쇄 완료 뒤 저장됩니다. 사용자가 이 시점에 받은 T_recoating으로 제어하는 방식을 선택했습니다. 측정부터 저장까지의 지연은 남으며, 약 0.25초 간격의 파일 확인과 기존 Save 처리 시간이 추가됩니다. 실제 램프 반영 시점은 원본 프로그램에 의존합니다.

이전 배포판의 원본 UI 응답 없음은 원인이 확정되지 않았습니다. 이번 변경은 외부 모듈의 표 접근 경로를 제거한 것으로, 원본 자체 Process 화면의 정지를 고쳤다고 주장하지 않습니다. 내부 운영 로그를 포함한 상세 조사 문서는 배포에 포함하지 않습니다.

## 검증

CSV·어댑터·세션·알고리즘·숨김 GUI·설정 보호 검사의 전체 결과는 `portable-validation.json`에 기록합니다. CSV 검사는 부분 행, 인용된 쉼표/줄바꿈, 미측정·오래된 행, 작업 교체, 역행·중복, 잘못된 헤더와 잘못된 수치, 후보 파일 중복, 새 파일 생성과 Windows 공유 읽기를 포함합니다.

실제 제품 세션·기본 알고리즘·CSV reader·native Sequence 어댑터를 사용하는 **18개 합성 통합 시나리오**가 통과했습니다. M1/S3 WebCam/Sequences 및 최소화, 부분 행, 최소화 상태 연결, Save 지연·확인 실패, 입력 중 지연, 입력 직후 IDLE, 미저장 설정, 후반 층, 연결 후 첫 CSV 생성, UI 지연 중 CSV 조회 지속을 검사했습니다. 별도의 Excel 옵션 시험과 세션 결합 시험은 단위 검사에 포함됩니다.

시험 창은 1,820행의 가상 Process 표에 접근성 요청·스크롤·Process 메뉴 전환이 오면 기록하고 실패하게 구성했습니다. 모든 시나리오에서 **표 접근 0회**였습니다. 정상 시 첫 두 관찰 저장 0회·세 번째 관찰 저장 1회, 중복 조회 추가 저장 0회와 non-IR 설정 보존을 확인했습니다. 부정·모호한 결과는 재시도하지 않습니다. 단계별 시간은 `validation/csv-route-results.json`에 있으며 시험 환경의 CSV 완료부터 처리 시간이지 물리 센서부터 램프 반응 시간은 아닙니다.

기존 실행 환경의 CSV를 자동으로 찾고 읽는 별도 읽기 전용 확인도 수행했습니다. 이 확인에서 원본 UI 조회나 IR 제어 명령은 실행하지 않았습니다. 운영 경로·PID·온도·시간 등의 상세 값은 이 보고서에 싣지 않습니다.

원본 Excel의 랜덤 80층 × 55열 4,400개와 입력 예시 67행 × 55열 3,685개, 총 **8,085개 수치**가 허용 오차 절대 1e-9·상대 1e-10에서 일치합니다. 수식 재현의 검증이며 장비 열 응답의 검증이 아닙니다.

## 고장 대응과 한계

GUI 작업자 분리, 제한된 큐·기록, 단일 실행/중복 연결 차단과 취소를 유지합니다. CSV 행과 작업을 확인하고 입력 전·Save 전 파일 크기/수정 시각을 다시 확인합니다. 기존 설정 전체를 대조하지만 외부에서 같은 순간 바뀌는 메모리 상태까지 원자적으로 잠글 수는 없습니다. 원본 설정의 동시 수동 편집과 층별 IR 예약이 있으면 제어와 충돌할 수 있습니다.

읽기만 실패한 원본 UI는 UNKNOWN으로 취급해 학습·IR 적용을 정지하고 CSV 표시는 계속합니다. 입력/Save 시작 후 시간 초과나 확인 실패는 결과 불명확으로 중단하며 재저장·복원·히터 정지를 하지 않습니다. 원본 UI가 지속해서 응답하지 않으면 기존 UI Save 경로로 IR을 적용할 수 없습니다.

CSV 탐색과 읽기는 크기·후보 수 제한을 둡니다. 기록이 오래됐거나 부분 행이면 제어하지 않습니다. 작업 시작 로그를 찾을 수 없거나 동일 시각 후보가 여러 개이면 자동 파일 선택을 거부합니다. S3의 필요한 기존 설정 누락도 자동 생성하지 않고 거부합니다. 센서 정상 측정과 실측 램프 출력의 일치는 독립적으로 검증하지 않습니다.

실장비 출력 변경·장시간 운전·열 응답 안정성은 미검증입니다. 새 CSV 수신 방식으로 원본 표를 반복 조회하는 원인은 제거했지만, 모의 시험만으로 원본 프로그램이 어떤 조건에서도 다운·지연·정지하지 않는다고 보장하지 않습니다.
