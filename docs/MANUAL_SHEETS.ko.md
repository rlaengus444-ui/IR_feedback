# 두 가지 수동 계산시트

기존 `IRFeedback-2026.10.28-slice.2` EXE에서 시트만 선택해 비교하는 평가용 파일입니다. 새 EXE 설치는 필요 없습니다. 실제 Excel COM 연결과 장비 운전은 미검증이며, 제어 알고리즘 최종 승인과 실제 장비 적용은 보류합니다.

| `01_IR_이미지기반_회복제어_2026.10.28.xlsx` | 정상 시 기존 제어; 진행 중 회복은 실측 종료 조건까지 계속 | 이전 층 분사 계획과 온도 급락이 일치하면 절대 기준 회복 제어로 과보상을 억제 |

## 기존 프로그램에서 선택

1. `Excel 수식 파일` 모드에서 내려받은 XLSX를 **찾아보기로 직접 선택**합니다.
2. 시트 `수동 테스트`, 층 `A13`, 온도 `B13`, 현재 IR `C13`, 결과 `D13`, 목표 `B5`, **이미지 시작셀 `BL13`**을 지정합니다.
3. 슬라이싱 ZIP 또는 이미지 전체를 선택하고 첫 이미지와 실제 층 번호를 맞춥니다. 기본 분사 색상은 흰색, DPI는 X/Y 각각 400이며 변경할 수 있습니다. 중앙 반경은 실제 사용값을 입력합니다.

기존 .2 EXE의 `수동 계산시트 저장 / 사용` 버튼은 이전 참고열 전용 시트를 내보냅니다. 이번 파일 대신 그 버튼으로 시트를 다시 생성하지 마세요. 이미지 시작셀을 비우면 이미지 기반 구분을 사용할 수 없습니다. 프로그램은 선택한 원본 XLSX를 수정하지 않습니다.

## 파우더 제어·분사층 고정 버전의 의미

현재 층 전체 이미지의 분사 픽셀이 하나라도 있으면 분사층입니다. 중앙 원 밖에만 분사가 있어도 분사층으로 취급합니다. 이미지가 유효하고 전체 도포율이 0일 때만 파우더층으로 판단합니다. 슬라이싱은 분사 계획이며 실제 분사 여부를 측정하는 센서는 아닙니다.

분사층에서는 `D=C`입니다. 파우더 마지막 층의 **실제 저장 출력**이 분사 구간에서 계속 유지됩니다. 적용되지 않았을 수도 있는 이전 권장 출력은 고정 기준으로 사용하지 않습니다. 분사 중 사용자가 실제 출력을 변경하면 변경된 실제 출력부터 유지하며, 이전 파우더 출력과의 연속성은 미확인으로 표시합니다.

이미지가 누락되거나 층을 확인할 수 없어도 `D=C`로 유지하고 학습하지 않습니다. 분사·미확인 구간의 온도 변화와 불완전한 학습 묶음을 다음 파우더 제어에 사용하지 않습니다. 파우더로 돌아오면 기존 G·알파·베타를 유지한 채 연속 관찰을 새로 시작합니다. 작업 재시작·층 번호 불연속은 설정된 초기 계수부터 시작합니다. 온도 `-1`은 유효한 측정값으로 취급하지 않습니다.

이 비교 버전은 사용자가 요청한 고정 정책에 따라 **분사층 온도가 높아져도 시트 자체에서 감출력하지 않습니다.** 장비의 독립적인 상한 감시를 대신하지 않습니다.

## 검증 범위

첫 번째 시트의 오프라인 재계산 83,700개 필드 및 과거 행 고정·상태 전환 2,790개 필드를 Python 참조와 대조했습니다. 두 번째 시트는 300행의 18,900개 필드를 대조했습니다. LibreOffice 재계산에서 수식 오류와 미래 행 오염은 없었고, 최대 수치 차이는 약 `5.7e-14`였습니다. 이 결과는 Microsoft Excel COM 또는 실제 장비 검증을 뜻하지 않습니다.

같은 300층 합성 열모델에서 기존 / 이미지 회복 / 분사층 고정의 센서 최고 온도는 각각 69.37 / 66.34 / 65.44°C, 평균 절대 오차는 1.645 / 1.069 / 1.297°C였습니다. 바인더 구간은 41–100층, 161–220층이며 목표는 65°C입니다. 냉각은 유한한 외란으로 모델링했고 실제 장비에서 열응답을 식별한 결과는 아닙니다. 분사층 고정은 과열 억제와 저온 회복 사이의 절충이 있으며, 이 한 모델에서의 순위가 모든 프린팅 조건에 적용되지는 않습니다.

이 대표 모델은 IR 60%에서 처음부터 65°C의 열평형이고 장비 이득의 시간 변화가 없는 조건입니다. 분사층 고정 버전의 명령은 이 예에서 300층 내내 60%로 유지되므로, 그 낮은 최고 온도는 이 초기 균형 조건에도 의존합니다.

첫 번째 알고리즘의 조건별 회복 지연과 잔여 성능 저하는 [이미지 회복 제어 문서](IMAGE_GUARD.ko.md)를 확인하세요.
