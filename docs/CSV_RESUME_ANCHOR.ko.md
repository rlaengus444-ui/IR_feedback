이 문서는 `2026.10.29-reconnect.1` 이후의 **오프라인 수정 후보** 기록입니다. 새 EXE 배포나 실제 장비 검증 완료를 뜻하지 않습니다. 내장 제어식·외부 계산시트·이미지 층 대응은 바꾸지 않습니다.

## 확인한 사실과 미확인 사항

사용자가 보낸 화면에는 작업 시작 내부 층 `500`, 로그 시작 `2026-10-29 09:50:38`, CSV Id `502`(내부 층 `501`), 행 시작 `09:51:25`, 완료 `09:52:33`이 표시됩니다. 오류는 이전 실행 기록을 제외한 뒤 재시작 시작 행을 확인하는 조건에서 발생했습니다.

사용자는 Monitoring CSV 세 파일을 올렸다고 확인했습니다. 분석 환경에 전달된 메시지에서는 CSV 첨부 참조를 확인하지 못했고 첨부·공유 작업 폴더에서도 해당 파일을 찾지 못했습니다. 업로드 여부와 이 분석 환경에서의 접근 가능 여부를 구별해야 합니다. 따라서 실제 파일의 내용·파일명·선택된 경로를 검사하거나 현장 원인을 확정하지 않았습니다. 화면과 같은 오류는 시작 행의 온도가 0인 경우, 완료 시각이 미기록인 경우, 시작 행 자체가 없는 경우, 시작 시각이 틀린 경우에 모두 재현됩니다. 실제 CSV와 필요 시 당시 장비 로그를 대조해야 이 경우들을 구별할 수 있습니다.

기존 코드에서 시작 행의 온도 0 또는 미기록 완료 시각을 먼저 건너뛰면, 그 행의 정확한 시작 층·시각도 함께 무시했습니다. 다음 유효 완료 행은 시작 층과 다르므로 연결 오류가 발생했습니다. 이 경로는 합성 CSV로 재현했습니다. 실제 사용자의 원인으로 단정하지 않습니다.

## 수정 범위

- 이전 실행 기록을 제외한 경우, 로그와 같은 시작 층 및 ±2초 이내의 유효 시작 시각으로 작업을 확인합니다. 층 +1 보정이나 시간 허용 범위 확대는 하지 않습니다.
- 온도 0 또는 미완료 행은 작업 확인에만 사용할 수 있습니다. 완료 시각은 유효한 값이거나 빈칸 또는 원본의 `DateTime.MinValue`여야 합니다. 임의의 잘못된 문자열·역전된 시각·비활성 온도 -1·잘못된 수치는 허용하지 않습니다.
- 미측정 행은 온도 관찰·관찰 키·적용 가능한 파일 토큰을 만들지 않습니다. 시작 행 확인 뒤에 과거 완료 행이 다시 나타나거나 중복 시작 행의 시각이 충돌하면 중단합니다.
- 첫 유효 완료 온도는 기준으로만 사용합니다. 부분 행이나 1 MiB 분할 읽기 때문에 여러 차례 조회가 필요해도, 완전한 파일 토큰과 유효 온도를 함께 반환할 때까지 이 조건을 유지합니다. 같은 묶음의 뒤쪽 행도 계산·Save 대상으로 삼지 않습니다.
- 작업 변경·파일 교체·축소·내용 재작성은 확인 상태와 기준값 대기를 초기화합니다. 파일·행 상한, 해시 대조, 신선도, 중복·역행·Save 보호는 유지합니다.
- 이전 기록이 없는 CSV의 기존 수신 방식, UI 자동 적용만 표시, 기본 BL13과 연결 종료 시 전체 그래프 CSV 자동 저장은 유지합니다.
