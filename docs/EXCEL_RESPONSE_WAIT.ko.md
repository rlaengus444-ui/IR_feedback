# Excel 지연과 연결 자동 복구

`2026.11.03-excel-wait.2` 검증 후보는 Excel 준비·이력 초기화·계산을 별도 작업에서 순서대로 처리합니다. Excel 응답을 기다리는 동안 BJT/CSV 수신과 그래프를 계속 갱신합니다. BJT의 IR 입력과 Save는 기존 세션에서만 실행합니다.

## 완료 이력 유지 수정

이전 `excel-wait.1`은 정상 완료 행이 5초의 신선도 제한을 넘으면 제어용 관찰 키를 제거했습니다. 오래된 행으로 계산·Save하지 않도록 하는 이 동작은 유지합니다. 그러나 키가 없어졌다는 이유로 이미 정상 계산한 Excel 이력까지 초기화해 통합 문서를 반복해서 다시 여는 문제가 있었습니다. 사용자 로그의 계산은 0.261~0.354초였지만 약 4초 뒤마다 이력을 초기화하고 재열기에 약 8초가 걸렸습니다. 초기화 뒤 다음 층을 새 기준으로 사용하면서 계산이 초기 유지 구간에 반복 진입할 수 있었습니다. 로그에는 내부 판정 필드가 없어 실제 PC에서 발생한 모든 초기화 사유를 확정할 수는 없으며, 코드 재현과 반복 주기가 일치합니다.

이번 수정은 현재 CSV의 완전하고 검증된 같은 행이 단지 오래된 경우, 해당 행의 출처·작업·층·설정 세대가 이미 수락한 계산과 정확히 같고 대기 중인 계산이 없을 때 확정 이력을 보존합니다. 이 증거는 이력 유지에만 사용합니다. 오래된 행으로 새 계산이나 Save를 허용하지 않습니다. 미확정 결과, 센서 오류, 제어 불가, CSV 토큰 부재, 작업·출처·설정·이미지 변경은 기존 초기화와 재확인을 유지합니다. 대기 중 목표 온도 변경은 기존 완료 행을 유지하며 다음 새 층부터 반영합니다.

## 수식만 읽어 계산하는 방식 검토

현재도 Excel은 연결 후 한 번 열어 둔 전용 통합 문서에 새 층 입력을 전달하고 수식을 재사용합니다. 일반적인 층 계산은 파일 재열기를 하지 않습니다. 이번 반복 재열기는 위 이력 초기화 문제에서 발생했습니다.

Excel 없이 수식만 읽어 계산하려면 시트 간 참조와 이전 행, 빈 셀·오류·형 변환·반올림·함수의 Excel 규칙을 재현해야 합니다. 제공된 두 계산시트는 약 22만~32만 개의 수식과 시트 간 참조를 포함하며 사용자가 수식을 바꾸는 기능도 지원해야 합니다. 기존 Python 알고리즘은 특정 이전 시트를 옮긴 구현으로 범용 Excel 계산기가 아닙니다. 따라서 이번 수정은 Excel 엔진·수식·완료 행 확정 방식을 유지합니다. 수식 전용 엔진은 별도 시제품과 실제 Excel 대조 검증 후 판단해야 하며 이번 버전에서 도입하지 않습니다.

## 작업자 없이 복구하는 경우

- Excel 응답 시간 초과·도우미 통신 실패: 진행 중 계산과 늦은 결과를 폐기합니다. 전용 PowerShell·Excel·읽기 작업 종료와 임시파일 정리를 확인한 뒤 처음 검증한 동일한 계산시트 바이트로 다시 준비합니다. 원본 파일이 나중에 바뀌어도 새 알고리즘으로 바꾸지 않습니다. 종료를 확인할 수 없는 프로세스가 있으면 중복 Excel을 만들지 않고 기다립니다. 사용자가 세션을 다시 시작해도 이 종료 확인을 건너뛰지 않습니다.
- BJT 읽기 응답 지연·일시적 CSV 파일 접근 실패: 데이터 수신을 재시도하며 IR 적용만 대기합니다. BJT 프로세스가 재시작되면 동일 실행 경로·장비의 창 하나만 다시 찾습니다. 처음 확인한 작업에만 기존 적용 권한을 유지하며 다른 작업은 관측만 합니다.
- 온도계 비활성 값 -1: 실제 온도로 사용하지 않으며 이전 정상 온도로 대신 제어하지 않습니다. 온도가 다시 유효해지면 새 기준 관찰과 다른 새 층을 확인합니다.

복구 재시도 간격은 2·5·15·30·60초 순으로 늘어나고 이후 최대 60초를 유지합니다. Excel 재시도 간격은 새 유효 계산을 수락해야 초기화합니다. 준비되지 않았을 때 수신한 층을 뒤늦게 계산하거나 Save하지 않습니다. 복구 후 현재 작업·층·CSV 출처·전체 Sequence 설정·센서 유효성과 신선도를 확인하고 기준 관찰 다음의 다른 새 층부터 자동 재개합니다. 목표나 이미지가 바뀌면 이전 계산 결과를 사용하지 않습니다.

## 관측은 유지하되 자동 적용을 보류하는 경우

수식·설정 오류, 통신 형식 오류, 충돌하거나 변경된 CSV 기록, 입력이나 Save의 실행 여부가 불명확한 오류는 자동 재저장을 하지 않습니다. 관측과 복구 시도는 유지하며 IR 제어를 보류합니다. 현재 설정이 우연히 같다는 이유만으로 미확인 Save가 해소됐다고 판단하지 않습니다. 원래 예외 종류·원인과 확인된 저장 기록은 상태 기록 및 `app/IR-module-error.log`에 남깁니다. 원본 BJT 종료·램프 ON/OFF·이전 IR 복원은 수행하지 않습니다.

자동 복구는 같은 논리 연결에서 진행합니다. 누적 그래프와 저장 확인 기록, 목표·이미지 변경 요청은 유지합니다. 사용자가 연결을 해제하거나 창을 닫으면 복구를 중지하고 전체 CSV·온도 PNG·IR PNG를 저장합니다. 같은 층을 먼저 표시한 뒤 Save가 확인된 경우에도 해당 층의 저장 성공 표시를 반영합니다. 두 채널 중 하나만 저장이 확인됐다면 그 채널의 확인 기록만 남깁니다.

## 진단과 기존 제어 동작

기존 오류 문구는 응답 시간 초과와 파이프 오류를 구별하지 못했습니다. 이번에는 초기화(init), 이력 초기화(reset), 층 계산(step), 소요·제한시간, 통합 문서 열기·입력 초기화·수식 계산·결과 확정 단계와 도우미 상태를 기록합니다. 이 정보 없이 특정 PC에서 Excel이 느려진 원인을 단정할 수는 없습니다.

Excel 초기화 응답 제한은 최소 30초, 층 계산은 기본 8초이며 전체 통합 문서를 다시 여는 이력 초기화는 최소 30초입니다. 이 수치는 실시간 장비 응답을 보장하지 않습니다. Excel 전체 재계산·이전 행 확정 방식과 제공 시트 수식은 유지합니다. 사용자 최대 IR 출력과 기존 1회 최대 5%p 증감 제한, 현재 설정·CSV·시각·Sequence 전체 입력 대조도 유지합니다.

## 검증 한계

Windows 합성 시험과 독립 검토 결과는 배포 페이지에 기록합니다. 실제 Excel COM, BJT·센서·PLC·램프 및 장시간 운전은 미검증이며 최종 알고리즘 승인과 실제 장비 적용은 보류합니다. 정상 범위의 오래된 센서값은 CSV만으로 판별할 수 없습니다. PC 전원·절전·권한·장비 자체 고장까지 자동 복구를 보장하지 않습니다.
