# Excel 응답 지연과 연결 유지

`2026.11.03-excel-wait.1`은 Excel 초기화·이력 초기화·계산을 별도 작업에서 순서대로 처리합니다. Excel이 응답을 기다리는 동안 BJT/CSV 수신과 그래프는 계속 갱신합니다. BJT의 IR 입력과 Save는 기존 세션에서만 실행합니다.

Excel 응답 시간 초과나 도우미 통신 오류가 나면 **연결과 수신을 유지하고 IR 자동 적용을 정지**합니다. 상태에 **연결 해제 후 재연결 필요**를 표시하며 자동으로 Excel을 재시작하거나 예전 층을 다시 계산·저장하지 않습니다. 장비의 기존 IR 설정이나 가열 ON/OFF를 바꾸지 않습니다. 사용자가 연결을 해제하고 재연결해야 계산 준비부터 다시 시작합니다.

기존 오류 문구는 응답 시간 초과와 파이프 오류를 같은 메시지로 표시했습니다. 이번에는 초기화(init), 이력 초기화(reset), 층 계산(step), 대기시간과 제한시간, 통합 문서 열기·입력 초기화·수식 계산·결과 확정 단계 및 도우미 상태를 기록합니다. 상태 기록과 `app/IR-module-error.log`에서 확인할 수 있습니다. 이 정보 없이 특정 PC에서 Excel이 느려진 원인을 단정할 수는 없습니다.

기존 초기화 응답 제한은 최소 30초, 층 계산은 기본 8초입니다. 전체 계산시트를 다시 여는 이력 초기화는 별도로 최소 30초를 허용합니다. 별도 작업 전체의 감시와 중지 처리를 추가했지만, 시간은 실시간 장비 응답을 보장하는 수치가 아닙니다. Excel 계산 순서·전체 재계산·이전 행 확정 방식과 제공 시트 수식은 유지합니다. 수십만 개의 수식, Excel 시작·통합 문서 열기 등이 지연 후보이나 실제 PC의 병목은 미확인입니다.

완료 결과는 현재 작업·층·CSV 출처·설정 세대·목표 변경 이력·이미지 세대·현재 IR·최대 출력이 일치해야 사용합니다. 계산 중 층이나 조건이 바뀌면 결과와 전용 계산 이력을 폐기하고 재확인합니다. Excel이 준비되지 않았을 때 관찰한 행을 뒤늦게 적용하지 않으며, 기준 관찰 후 다른 새 층부터 재개합니다. 목표만 정상 변경하는 경우에는 이미 확정된 이전 행을 유지합니다.

기존 최대 IR 출력, 1회 최대 5%p 증감 제한, 잘못된 측정·시각·CSV·Sequence 입력 확인과 Save 결과 불명확 시 중단을 유지합니다. 수식 오류나 잘못된 결과를 응답 지연으로 취급하지 않습니다. 이전 채널의 Save가 확인된 뒤 다음 채널에서 오류가 나면 확인된 저장 기록만 남깁니다.

Windows Excel COM 및 실제 BJT·센서·PLC·램프·장시간 운전은 미검증입니다. 합성 시험과 독립 검토 결과는 GitHub 배포 페이지에 별도로 기록합니다. 최종 알고리즘 승인과 실제 장비 적용은 보류합니다.
