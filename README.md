# IR 피드백 외부 모듈

`2026.11.03-excel-wait.1` 검증 후보입니다. Excel 계산·초기화·이력 초기화를 CSV 수신과 분리했습니다. 응답 시간 초과 또는 Excel 통신 오류가 나면 연결·CSV·그래프를 유지하고 IR 자동 적용을 정지합니다. 연결 해제 후 재연결해야 계산을 다시 시작하며 늦은 결과를 재사용하지 않습니다. [지연 처리와 검증 범위](docs/EXCEL_RESPONSE_WAIT.ko.md)를 확인하세요. 연결 전에 사용자 최대 IR 출력(0~100%, 기본 100%)을 설정할 수 있습니다. 기본 및 Excel 알고리즘의 적용값에 이 상한과 기존 1회 최대 5%p 증감 제한을 적용합니다. 현재 설정이 상한보다 높으면 급격히 낮추지 않고 Save를 대기하며 CSV와 그래프는 계속 유지합니다. [출력 제한과 검증 범위](docs/IR_OUTPUT_LIMIT.ko.md)를 확인하세요.

슬라이싱 이미지는 ZIP 또는 이미지 다중 선택으로 수동 분석합니다. 연결 중 새 분석이 완료되면 준비된 이미지셋으로 교체할 수 있습니다. 기존 수동 입력·계산식·계산시트와 설정 변경 시 연결 유지, 연결 종료 시 CSV·두 PNG 저장은 유지합니다. 최종 제어 승인과 실제 장비 적용은 보류합니다.

UI 자동 적용만 표시하며 이미지 시작셀 기본값은 BL13입니다. 정상 해제·오류 종료·프로그램 닫기 시 누적 그래프 데이터를 전체 CSV와 두 PNG로 자동 저장하고, 상태 기록에 파일 위치를 남깁니다.

기존 Monitoring CSV의 `TemperaturePostRecoating`으로 IR 권장값을 계산합니다. 층별 그래프는 최근 100층을 표시하며 전체보기와 전체 CSV 저장을 지원합니다. 새 슬라이싱 이미지 탭에서는 ZIP 또는 이미지 다중 선택으로 중앙 반경 mm의 도포 데이터를 분석하고, 편집 가능한 수동 Excel 시트로 저장합니다. 기본 분사 색상은 흰색, DPI는 400×400이며 변경할 수 있습니다. 기존 G·알파·베타와 권장출력 수식은 유지합니다.

배포 ZIP을 새 폴더에 전체 해제한 뒤 `IRFeedback.exe`를 실행합니다. Python은 포함되며 별도 설치하지 않습니다. 화면의 모드는 UI 자동 적용으로 고정되며 사용자가 연결을 눌러야 준비를 시작합니다. Excel 수식 모드에는 Microsoft Excel 데스크톱이 필요합니다. 제공 계산시트의 이미지 시작셀 기본값은 `BL13`이며 다른 양식은 수정하거나 비울 수 있습니다.
