# IR 피드백 외부 모듈

`2026.10.28-slice.1` 검증 후보입니다. Windows EXE·Excel 연동의 배포 검증을 진행 중이며 정식 업로드 전입니다. 제어 알고리즘 최종 승인과 실제 장비 적용은 보류합니다.

기존 Monitoring CSV의 `TemperaturePostRecoating`으로 IR 권장값을 계산합니다. 층별 그래프는 최근 100층을 표시하며 전체보기와 전체 CSV 저장을 지원합니다. 새 슬라이싱 이미지 탭에서는 ZIP 또는 이미지 다중 선택으로 중앙 반경 mm의 도포 데이터를 분석하고, 편집 가능한 수동 Excel 시트로 저장합니다. 기본 분사 색상은 흰색, DPI는 400×400이며 변경할 수 있습니다. 기존 G·알파·베타와 권장출력 수식은 유지합니다.

배포 ZIP을 새 폴더에 전체 해제한 뒤 `IRFeedback.exe`를 실행합니다. Python은 포함되며 별도 설치하지 않습니다. Excel 수식 모드에는 Microsoft Excel 데스크톱이 필요합니다. 처음에는 조회 또는 계산 미리보기로 사용하세요.

- [전체 조작 방법](app/README.ko.md)
- [슬라이싱 이미지와 수동시트](docs/SLICE_INPUT.ko.md)
- [이번 후보의 검증 상태](docs/SLICE_VALIDATION.ko.md)

온도계 비활성 값 -1은 제어 입력에서 차단합니다. 정상 범위의 오래된 센서값은 CSV만으로 구별할 수 없습니다. 슬라이싱 이미지는 예정된 도포 패턴이며 실제 센서 위치·분사 실행·건조 완료를 증명하지 않습니다. 실제 S3 센서·PLC·램프 출력과 장시간 운전은 검증하지 않았습니다.
