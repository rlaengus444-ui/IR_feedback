프린팅 중지·재시작과 컨트롤러 PID 변경 후, 작업자 재연결 없이 IR 피드백을 자동 재개하도록 보완한 M1·S3용 평가판입니다.

- 새 작업 시작 로그·CSV·AUTO 상태와 전체 설정을 확인한 뒤 새 기준 및 더 높은 새 완료 층부터 재개합니다. 같은 초의 재시작도 시작 기록의 실제 위치로 구분합니다.
- 같은 실행파일·장비인 창을 완전하게 검색하고 후보가 하나면 새 PID로 자동 연결합니다. 실제 PID도 화면에 갱신합니다.
- 느린 설정 확인 때문에 온도가 만료되어 재개가 반복 대기하던 경로, 연결 복구 도중 조회 전용에 남던 경로를 수정했습니다.
- 입력 전에 CSV 유효 시간이 만료되면 권장값만 폐기합니다. 같은 작업·제어 조건에서 확정된 실제 입력 이력과 연결은 유지하고 다음 새 층에서 자동 재개합니다. 5초 신선도 제한과 모든 필드·저장 검사는 유지하고, 입력 직전에는 남은 시간도 확인합니다.
- Save 요청은 한 번만 전송합니다. UI가 잠시 저장 처리 중이면 최대 1초 동안 응답만 확인하며, IR 읽기와 저장 파일의 전체 확인을 거칩니다. 완료가 불확실하면 같은 Save를 다시 보내지 않습니다.
- 기존 목표 온도·연결 중 IR 상한 변경·층당 최대 5%p 제한·수동 이미지 입력·최근 100층/전체 그래프·CSV 및 온도/IR PNG 자동 저장을 유지합니다.
- 작업이 바뀌면 이전 이미지 분석은 보존하고 현재 작업 확인 전까지 이미지 참고값을 미확인 처리합니다. 같은 분석을 쓰려면 '현재 작업에 이미지 적용'을 사용합니다. 계산시트 두 종류는 기존 XLSX를 그대로 사용합니다.

기존 모듈을 닫고 ZIP 전체를 새 폴더에 압축 해제한 뒤 IRFeedback.exe를 실행하세요. app의 설정 JSON·DLL과 runtime을 함께 유지해야 합니다. Excel 수식 모드는 Excel 데스크톱이 필요합니다.
